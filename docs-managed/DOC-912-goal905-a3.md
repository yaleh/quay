## 演练记录

本文档是 GOAL-905（goal 分支第二次演练）A 批的第 3 篇，内容刻意无害。

### 本篇负责验证什么

**真实大小并入。** 上一次演练（GOAL-904）只用了一篇短文档，无法区分「合并真的搬运了
内容」与「合并只搬运了一个路径」。A 批八篇每篇都不少于 30 行，整批合起来是一个
可被 `git diff --stat` 看见的字节量——并入 goal 分支后，增删行数应该对得上，而不是
一个接近零的读数。

### 体量与判据

| 量 | 本次取值 | 为什么 |
|---|---|---|
| 单篇行数下限 | 30 | 任务 AC 明文要求 |
| 单篇正文是否有表 | 有 | 让正文不是纯散文 |
| 八篇是否同文 | 否 | 复制粘贴会让并入读数失真 |
| 是否改产品代码 | 否 | 演练只搬文档，不动代码 |

### 为什么不用「一篇长文」

一篇长文只能验证「一次大合并」，验证不了「多次小合并互相不踩」。八篇短文的组合能同时
覆盖两件事：单次并入的搬运完整性，以及多条任务并发落地时的互不干扰。

### 可见性边界

本文档只存在于 `goal/GOAL-905` 分支上。并入 `develop` 之前，预览实例的 `/doc` 页能列出
`DOC-912`，生产实例列不出；这个差异是演练的观测对象，不是需要修复的缺陷。
