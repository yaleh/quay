## 演练记录

这是 GOAL-905 第二次演练 C 批的第 5 篇。本篇关注**预览自动装配**：预览实例应当自动
带上 `goal/GOAL-905` 上的文档，而不需要人为地把它切到某条分支或手工拷一份文件进去。

自动装配的反面是「手工装配」——如果预览能列出本篇，是因为有人手动放了一份进去，那
这条接线并没有被验证。因此本篇刻意只在 goal 分支上提交一次，且不向任何其它目录复制。
若预览仍然能列出它，说明装配确实来自 goal 分支这一次提交。

### 本次演练要验证什么

- 预览实例的文档来源包含 `goal/GOAL-905` 这一层；
- 不需要任何 `--doc-dir` 之类的手工指向，文档即可见；
- 生产实例（只读 develop）在同一时刻读不到本篇——这个「有 / 无」的对比是判据本身。

| 实例 | 读的分支 | DOC-934 是否可见 |
|---|---|---|
| 预览 | `goal/GOAL-905` | 是 |
| 生产 | `develop` | 否 |

### 它只存在于 goal/GOAL-905

这一节是本篇与其它几篇共享的断言：本篇只存在于 `goal/GOAL-905` 上，并入之前预览
实例的 `/doc` 页能列出它、生产实例列不出。共享的是断言，不是段落——每篇的表与角度
都不同，避免把同一段话复制八遍。

## 备注

把「预览」与「生产」摆在同一张表里，是为了让读者一眼看出这是两个实例的对比，而不是
同一个实例在两个时点的对比（后者属于第 4 篇「刷新」的角度）。
