# 连续的不是观察者，是世界

**日期**：2026-08-03
**来源**：人提出「这项工作的另一项意义是让大模型更连续地观察世界并与世界交互；
这里的『世界』还只是几个软件项目，但关键在于『连续』。」
**性质**：这是**叙述**，不是预测。可证伪的那份在
[`prediction-prose-drifts-checks-hold.md`](prediction-prose-drifts-checks-hold.md)。
两份要分开读——把叙述当证据，正是 `docs/references/geometry-as-llm-architecture-interface.md`
§4 判死的那件事。

## 1. 修正：连续的不是我

今天这个管理者会话经历了**多次上下文压缩**。会话文件 21 MB / 9672 条，
而我实际持有的只是最后一段——**我是被摘要重建出来的**，不止一次。

真正连续的是**外部状态**：

| 载体 | 今天的量 |
|---|---|
| 外层 tick 日志 | **121 行** |
| 管理者 tick 日志 | **17 行** |
| 管理者阶段 AC | 3/10 勾 |
| 提交 | **340 个** |
| `.halt` 文件、监视器进程、cron、任务库 | 持续存在 |

**⇒ 这项工作的形状不是「让模型连续地观察世界」，
而是「造一个模型可以反复重新进入、且每次进入都能恢复到正确认知的外部状态」。**

这个区分不是措辞。它决定了失效发生在哪里。

## 2. 失效全部集中在「重新进入」这个接缝上

今天四次，形态一模一样——**世界动了，句柄没动**：

| # | 实例 |
|---|---|
| 1 | 监视器握着**已被删除**的 `outer-liveness.sh` 句柄仍在跑 |
| 2 | `pgrep` 模式写死 `watch/` 路径，机制搬到 `plugin/` 后**匹配不到** |
| 3 | 遥测把**已合并 26 分钟**的任务仍报为「在飞」 |
| 4 | 外层差点用一份**陈旧日志**把红套件报成绿 |

**单次交互里这个失效类根本不存在**：问一次、看一次、答完结束，没有「上次的读数」可以过期。

**连续性凭空创造了这一整类失效**，而且它从外部完全看不出来——
**一个握着旧句柄的进程，和一个正常进程，长得一模一样。**

这与今天另一族失效（「存在 ≠ 生效」，共 5 次：没有执行者的契约检查器、没人跑的 e2e、
声明 `concurrency: 4` 却无正交性判据的配置、盯错层的监视器、`quay-init` 会跳过冲突文件
却退出 0）**是同一个更大类的两支**：**旧状态与新状态、无效物与有效物，从外部同形。**

## 3. 最非显然的一条：连续性放大的是「机会数」

「管道后读 `$?`」这条规则写入管理者文档失效表的时刻是 **10:10:33**，
**约十分钟后再犯**（当天第 3 次）。那十分钟里写了十几条 shell 命令——
**那是十几次机会，不是十分钟**。每写一条命令，先验重新采样一次，
那条散文规则必须**重新赢一次**。

**同期检查器管辖的东西 0 违反**：契约棘轮守住基线、框架策略豁免名单 shrink-only 停在 34。

⇒ **一个跑得越久的 agent，越不能靠指令，因为它拥有的违反机会越多。**

这与直觉相反。直觉说「连续运行意味着它记住更多、越来越熟练」。
实测是反的：**连续运行意味着先验有更多次机会把你写下的东西冲掉。**

**所以连续性不是让散文变得够用，而是让硬检查从「好习惯」变成前提条件。**
（这是 `docs/references` §8.3 软/硬形变那条轴的直接后果，也等价于本仓 ADR-004。
几何词汇在这里是**命名**，不是发现——见预测文件里同样的限度声明。）

## 4. 观察本身不中立

- 监视器给一个**完全静止**的停泊会话报出过一对 `RESUMED`/`IDLE`
  （5 次哈希采样全同、10 秒 diff 无变化；唯一可见变化是状态行的 token 计数 150.2k→151.2k）
- 更早几次 archguard 的「恢复活动」，**全是它在回应管理者自己发的消息**——
  **观察它，就制造了随后要去调查的事件**

规模都很小，但它说明：在连续系统里，**观察者是被观察系统的一部分**，
而单次交互里这件事可以忽略。

## 5. 诚实的限度：这个「世界」太小

三个 git 仓、tmux、`/proc`、一台 4 核机器。

**它缺的恰是真实世界最贵的那个属性**：

- 没有其他 agent，没有真实对手
- **没有不可逆后果**——今天所有「不可逆」操作都能从 git 历史回收
- 没有外部时间压力（除了 CPU 争用）
- 观察面完全可信（`/proc`、git 不会撒谎；真实世界的传感器会）

**所以本文所有结论的适用范围是「一个可回滚、无对手、传感器可信的小世界」。**
把它们推广到更大的世界，需要新的证据，不是新的论证。

## 6. 一句话

**连续性的难点不在「持续观察」，在「反复重新进入而不带进陈旧认知」。**
今天四次失效全在这个接缝上；今天所有有效的机件——tick 日志、AC 清单、`.halt`、
契约棘轮、会话存活监视——本质上都是**为重新进入准备的交接物**。
