# 监视器的损失函数（用于指导设计，不进脚本）

**日期**：2026-08-03
**来源**：人提出「构造一个损失函数来分析 monitor：误报造成的 LLM token 消耗、
漏报造成的额外等待时间。**不用做到脚本里，只是用于指导其设计**。」
**性质**：设计分析。数字来自当天实测与可数的结构参数；**估计值明确标注**。

---

## 1. 形式

```
L = Σ_误报 (token 成本) + Σ_漏报 (额外等待时间 × 时间单价)
```

两项的单位不同，**不强行折算**——它们各自的结构比它们的和更有指导意义。

---

## 2. 漏报侧：**代价分两类，差好几个数量级**

**关键结构参数**：外层 loop 周期 **20 分钟**、管理者 tick **30 分钟**。

### 2a. 可自愈的漏报 —— 代价有上界且很小

外层空闲、批次间隙这类状态，**loop 下一次触发就自行恢复**。

**⇒ 漏报代价 ≤ 20 分钟延迟，无持久损害。**

### 2b. 不可自愈的漏报 —— 代价上界 = 直到有人问

当天实例：

| 实例 | 实际持续 | 怎么被发现的 |
|---|---|---|
| 监视器盯错层（看内层不看外层） | **18 小时** | 人问才发现 |
| 监视器跑旧版本 | 50 分钟 | 机制比对（当天新加的）才发现 |
| 外层未挂 `session-liveness` | 约 1 小时 | 人提示才发现 |

这三类**不会自愈**：会话死了不会自己活过来，挂错的监视器不会自己挂对。
**没有外部干预，代价随时间线性增长且无上界。**

### 2c. 直接推论：两类应当反向调参

| | 漏报代价 | 调参方向 |
|---|---|---|
| 可自愈（空闲、批次间隙） | ≤20 分钟，有界 | **容忍漏报**，少报 |
| 不可自愈（会话死、loop 死、跑旧版、没挂上） | 无界 | **绝不漏报**，宁可误报 |

**这是从损失函数推出来的，不是口味。** 而当前实现对两类用的是同一套阈值。

---

## 3. 误报侧：**主导变量不是事件率，是「可打发性」**

当天两个极端（成本按工具调用次数计，token 成正比）：

| 误报 | 处理动作 | 工具调用 |
|---|---|---|
| 「`SESSION-RESUMED`，我刚给它发过消息」 | 认出成因，一行打发 | **1** |
| archguard 停泊会话的假阳性 | 5 次哈希采样 + diff + 追根因 + 交接 | **约 4** |

**差约 4–5 倍，而分野是【事件自带的上下文是否足以当场打发】。**

### 事件率的实际量级

`LOOP_MIN=0` 下健康周期每 20 分钟一对 = **6 次/小时/活跃项目**。
当前活跃项目 1 个。即便三个项目全开也只有 18 次/小时。

**⇒ 在这个量级上，事件率不是主导项。**
6 次/小时 × 1 次工具调用 与 6 次/小时 × 4 次工具调用，差的是 18 次调用/小时——
**这才是可优化的部分，而它取决于事件负载而非阈值。**

### 直接推论

**投资应当放在事件的 payload，不是阈值调优。**

一个自带判断依据的事件（如 `SESSION-IDLE …；心跳 2 分钟前更新`）
让接收者一行打发；一个只说「状态变了」的事件强迫接收者去调查。
**同样的误报率，成本差 4–5 倍。**

---

## 4. 三条设计结论

1. **按「是否自愈」分两类事件，用不同阈值**——
   可自愈的从严（少报），不可自愈的从宽（宁可误报）。当前实现两类同参。

2. **每个事件必须携带足以当场打发的上下文**——
   这比降低误报率更划算，因为它把昂贵误报变成便宜误报，而不是消灭误报。
   人已明确：**不追求假阳性为零**。

3. **不可自愈类必须有独立的正控制**——
   因为它们的漏报代价无界，而**漏报本身是静默的**：
   一个盯错层的监视器与一个正确的监视器从外部同形（当天 18 小时的实例）。
   **靠观察事件流永远发现不了这一类**，只能靠定期主动验证。

---

## 5. 这个模型没覆盖的

- **误报的次生损害**：我调查一个假阳性时，可能对系统做出错误动作。
  当天有一例——我据一个假前提让 archguard 停 loop，而它的 loop 早就停了。
  那次无害，但模型里没有这一项。
- **人的时间**：人两次比我先看到空闲外层，那是**人的等待**，本模型只算了机器与 token。
- **两项单位不同**，本文不折算。若要折算，需要一个「1 分钟延迟值多少 token」的汇率，
  而那个汇率取决于外部时间压力——**这个环境里几乎没有**（见
  [`continuity-is-in-the-world-not-the-observer.md`](continuity-is-in-the-world-not-the-observer.md) §5）。
