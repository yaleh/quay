## 4. 可取假的结论与其反向指标

### 结论 A：`Touches` 声明条目数与返工次数**正相关**，且不是 bodyLen 的代理

- 实测：Spearman ρ = **0.2245**。
- **反向指标 1（置换零分布）**：把 (任务, 执行次数) 的配对独立打乱 2000 次，|ρ| 的 p50 = 0.0250、p95 = 0.0722、**max = 0.1299**，经验 p = 0.0005。
  ⇒ **若该关联只是配对噪声，打乱后应能取到 0.22 这个量级；实测取不到**（最大值 0.1299 < 实测 0.2245）。
- **反向指标 2（偏相关）**：`Touches` 与 `bodyLen` 本身相关（ρ = 0.4171），所以「Touches 预测返工」可能是「大任务预测返工」。控制 bodyLen 后 ρ = **0.1945**（几乎不降）；
  反向控制 touches 后，`bodyLen` 的 ρ 从 0.1341 **塌到 0.0501**。
  ⇒ **两个方向的预测不对称**：Touches 不是 bodyLen 的代理，bodyLen 反而已被 Touches 完全中介。
  ⇒ 若结论 A 为假，应观察到 `touchesVsExecutions_givenBodyLen` 塌向 0——实测 0.1945，未塌。

### 结论 B（弱信号，同样可取假）：`depends_on` 条数**统计上为正、实务上不可用**

- 实测 ρ = 0.1052，置换检验 p = 0.0065（零分布 p95 = 0.0734）——**统计上为正**，不能报成「无关」。
- **但它在立案期不可用**：充分样本的箱覆盖了 97.6% 的任务，而其中 **86.8% 全部落在同一个 `0` 箱**
  （中位 2、均值 2.57，与全场中位 2、均值 2.71 几乎相同）。
  一个把 87% 的任务归进同一组、且该组与全场同分布的因子，**没有区分力**——ρ 的显著性来自其余 13% 的尾部任务，不来自可操作的立案期判断。
- **反向读数**：若 `depends_on` 在立案期真的可用，它应能把任务分成返工水平明显不同的组；实测「0 条」组与全场同分布（见上），
  且非零箱的中位全部为 2，与 0 箱相同。

## 5. 混杂因素：显式处理（AC4）

任务**难度不可观测**。「难任务既 touches 多、又返工多」能产生与结论 A 完全相同的表——本报告无法排除它。

- **不能排除**：难度在层内仍然与 Touches 共变。

### 5.2 观测窗控制（任务年龄）

`executions` 是**有上界**的量：进入 worker 池越晚的任务，越没有时间累积轮次。
**曝露时长**（本任务第一条 worker-outcome 记录距今的天数，**直接取自生产载体**）因此是一等混杂因子，实测：

| 曝露天数 vs | Spearman ρ |
|---|---|
| `executions` | 0.0983 |
| `touchesFileCount` | -0.0812 |
| `hasGoalAc` | -0.4282 |
| `bodyLen` | -0.5846 |

⇒ **`hasGoalAc` 与曝露时长强负相关（-0.4282）**：有 `goal_ac` 的任务系统性更新。
其分组差异（见 §3）因此**不能**读作「加了 goal_ac 就会少返工」，最省事的解释是「新任务还没来得及返工」。
**`hasGoalAc` 在本报告中只作观察项，不作结论。**

控制手段：把总体限制在 **2026-08-31 之前就已进入 worker 池**的子集（每条的观测跑道 ≥14 天）。
主控制用**载体派生的曝露时长**；副控制用**git 派生的任务文件年龄**（更弱的代理，因为「文件存在久」不等于「在池里久」）：

| 读数 | 全体（n=721） | 主：曝露 ≥14 天（n=247） | 副：文件 ≥14 天（n=248） |
|---|---|---|---|
| 中位 executions | 2 | 2 | 2 |
| 均值 executions | 2.71 | 3.25 | 3.24 |
| ρ(Touches, executions) | 0.2245 | **0.2089** | 0.2145 |
| ρ(年龄, executions)——该子集内 | 0.0983 | **-0.0495** | 0.0143 |

- **能排除**：关联不是「全体里混着大量新任务」造成的——限制观测跑道后仍然成立（主控制 0.2089 / 副控制 0.2145 vs 全体 0.2245）；
  且**曝露时长在主控制子集内已不再与返工相关**（ρ = -0.0495），说明这条控制确实摁住了曝露这一混杂因子，而不是换了个说法重述同一批数据。
- ⚠️ 两列若**方向相反**，以主控制为准（副控制的「文件年龄」与曝露时长不是同一个量）；此处两列同号。
- **不能排除**：难度；以及「已经被执行过的任务才进入样本」这一选择效应（§1 的 1427 个未入池任务不在样本内）。

**反向读数（若建议为假，应观察到什么）**：

## 7. 已知限制

- 分析总体是**进入过 worker 池的任务**，不是板上全部任务（1427 个任务文件不在样本内）——这是选择效应，不是全量。
- 难度不可观测（§5）；本报告所有关联词都是「相关」，没有任何因果读法。
- `executions` 计的是 worker 执行**条数**，包含 `exited-not-landed`/`failed`/`killed` 各类（见 §0 状态全表），不等于「人工介入次数」。
- 分箱边界是**固定**的（1–2 / 3–4 / 5–6 / 7–9 / 10–14 / 15+），在本次读数上一次选定的；跨数据集比较时不要重新分箱。
- 样本不足的箱**不给统计量**，因此某些因子的表里会出现大片「—」——那是**能力边界**，不是缺数据。
- 置换检验的 p 值是经验值（(ge+1)/(B+1)），$B=2000$，分辨率下界约 5.0e-4。
