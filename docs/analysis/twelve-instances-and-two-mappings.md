## 2. 人发现的那四条有共同点

| # | 我做了什么 | 我漏了什么 |
|---|---|---|
| 4 | 每 tick 记压力与 load | **从没问过「我的监视器在看什么」** |
| 9 | e2e 有双向负控制、有改名测试 | 它查的是**文件内容里的路径字符串** |
| 10 | `/live` 降级完美、「无数据 vs 读失败」已分开 | **它显示的与事实相反** |
| 12 | 验 AC3 查了三提交链、逐字节比对、幂等性 | **唯独没查「内层在跑什么」** |

**⇒ 我设计的检查，测的是我设想的失效。**

而人四次都不是通过设计检查找到的——是**让我起一个服务、看一个页面、看一眼屏幕**。

**这不是「人比模型强」，是通道不同**：
人提供**真实使用**与**对屏幕上实际有什么的注意**；
管理者提供**测量**与**跨项目状态**；
外层提供**领域自查**。**三条通道的盲区互不重叠。**

这正是文档 (c)「放大的是人机通道而非任一端」的实测形态。

## 3. 挣到的修正：`Π_{S→E}` 不是一次映射，是两次

文档把 `Π_{S→E}`（region → executable check）当作一次映射：把连续意图钉成可执行守卫。

**今天的十二次说明它有两步，而失败集中在第二步**：

```
意图 ──①──> 守卫（写出来、可执行）──②──> 接线（真的会被执行）
```

| 死在哪一步 | 实例 |
|---|---|
| ② | #1 契约检查器**写好了、没有执行者** |
| ② | #2 e2e **写好了、没人跑** |
| ② | #3 `concurrency: 4` **声明了、没有判据脚本** |
| ② | #7 机制**装了、循环没起** |
| ② | #12 内层文档**铺了、没有读者** |
| ② | #11 遥测脚本**在、没往该写的地方写** |
| ①的伪装 | #6 负控制**存在，但探针不可能失败** |

**至少六次死在第二步，一次死在「第一步看起来完成了其实没有」。**

**为什么这一步在文档里没有名字**：因为在几何叙述里，一个 executable check 一旦写出来就**默认在 `E` 里**——
而现实中「写出来」和「在 `E` 里」之间隔着**接线**，而接线本身是软的、会被忘记、且**从外部与已接线同形**。

**⇒ 补一条判据**：一个守卫是否在 `E` 里，判据不是「它存在」，
而是「**移除它会不会让某次运行失败**」。今天所有第二步的失败，都能被这一问当场问出来。

## 4. (a) 与连续动力学层：修正——「我没用」不等于「没价值」

**人指出了一个我犯的推理错**（2026-08-03）：本节原写「(a) 今天零次」并据此不算它的功劳——
**但「我没用」与「没有价值」是两件事**，我把前者的证据当成了后者的结论。
**这与本文第 2 节批评我自己的那条同形**：用一个不足以支撑结论的观测下了结论。

### 重做：五轴问法能否事先问出这十二次

轴的定义（ADR-006/007）：`L_T` 可行性/测试、`L_C` 约束/类型、
`L_D` 描述长度/依赖结构、`L_G` 是否重造已有抽象、`L_S` 扰动下的行为方差。

| # | 落在哪根轴 | 能否事先问出 |
|---|---|---|
| 1 契约检查器无执行者 | `L_T` | ✓「这个守卫在真值面上吗」 |
| 2 e2e 没人跑 | `L_T` | ✓ 同上 |
| 3 `concurrency:4` 无判据 | `L_C` | ✓「这条约束被 instrument 了吗」 |
| 4 监视器盯错层 | `L_T` | ✓「这个仪器点亮的是哪根轴」 |
| **6 改名负控制不可能失败** | **`L_S`** | ✓✓ **正是扰动方差那根轴** |
| 9 运行时依赖开发树 | `L_D` | ✓「它运行时依赖什么」 |
| 10 `/live` 正确但无用 | `L_T` | ✓「有数据时的行为测过吗」 |
| 12 内层从没跑过 fast mode | `L_T` | ✓「内层的行为有仪器吗」 |

**第 6 条是决定性的**：管理者今天**独立得出**「负控制必须能在缺陷存在时失败」，
**而那就是 `L_S` 的内容**——从失败反推出来的，**而一份类型化清单本可以事先给出**。
同理，第 3 节那条「`Π_{S→E}` 是两次映射」本质是 `L_T` 的一个说法：
**没接线的守卫不在真值面上**。

**⇒ 类型化清单的价值恰在它是【类型化】的**：今天漏掉的四次都不是「问了答错」，
是**根本没想到问这一类**——那正是固定清单防的东西。
**(a) 今天零次，是关于习惯的事实，不是关于价值的结论。**

### 连续动力学层：判断不变，但理由变准

- **Fisher / 本征维度 / ρ**：仍**举不出一个它们会改变的决定**，
  且能说清为什么——**它们需要一个状态空间的参数化，而这里没有**。与 §4 自我判决一致。
- **但「动力学」这个类别今天是中心的**：Σ/墙钟比（有效并行度 7.1）、
  run-to-run 方差（sigma 297.6s）、**按「应用机会」计的侵蚀速率**、队列深度 vs 消耗速率——
  **全是动力学量，只是用初等统计而非微分几何测的**。

**⇒ 可能不是「连续动力学层无价值」，而是文档挑了一组在这里取不到的量。**
这个区分本文初稿没有做出来。

## 5. 限度

- 一天、一台机器、两个真实项目、一个人
- 「三条通道盲区互不重叠」是**今天的分布**，不是**结构性证明**——
  换一个人、换一组任务，分布会变
- 第 3 节那条修正是**从失败反推的**，不是预测出来的；
  它的检验要等下一次有人**在写守卫时就问「移除它会不会让某次运行失败」**，
  看那一问能不能在事前挡住第二步的失败
