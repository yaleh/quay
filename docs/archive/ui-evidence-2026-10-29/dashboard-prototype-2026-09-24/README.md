# Quay Dashboard · Harbor

可交互的独立静态原型，用于确认 Dashboard 的视觉方向和信息组织，再讨论全站改进范围。

## 打开

预览地址：<http://localhost:12932>

从仓库根目录启动（零依赖、无构建步骤）：

```sh
node docs/design/dashboard-prototype-2026-09-24/serve.mjs
```

默认监听 `0.0.0.0:12932`，只提供此目录的三个页面资源，不暴露仓库文件。可用 `QUAY_PROTOTYPE_PORT` 指定其他端口。也可直接打开 `index.html`。

现有 Quay 页面链接使用访问原型时的 hostname 和端口 `12931`，在新标签页打开。详情弹窗、时间筛选和搜索仅影响本地显示。

## 设计方向

- 暖白画布、松绿运行面板、浅绿进度与状态；色彩服务于阅读层级。
- 桌面采用固定分组侧栏，运行、目标、历史有明确层次；窄屏使用独立滚动抽屉。
- 首屏四个指标回答：目标多少、正在做什么、验证是否通过、是否需要接手。
- 运行面板将执行、验证、落地放在共同时间尺度上，并诚实呈现空闲状态。
- 目标卡保留目标标题、验收分子/分母、关联任务数；详细证据渐进展开。
- 活动流区分提交、测试、落地，避免把三种不同证据混为一种“完成”。

主要设计参数：背景 `#f7f8f4`、运行面板 `#18382b`、导航 `#172e25`、强调 `#d2eda1`；卡片圆角 15px；侧栏宽 222px；主内容左右边距 34px。文字使用系统字体，无第三方字体或 CDN 请求。

## 可体验的交互

- 点击四个指标、目标卡、活动行、时间轴片段，查看详情。
- 时间窗口 `1h / 3h / 6h`：1h 呈现真实空闲态，3h/6h 重新定位已收集的历史区间。
- 活动流 `全部 / 落地 / 测试 / 提交` 实际筛选记录。
- `Ctrl+K` / `⌘K` 搜索页面、目标、活动；上下方向键选择，Enter 打开，Esc 关闭。
- 手机导航支持明确关闭按钮、遮罩关闭、Esc、焦点约束；关闭时不会进入键盘导航顺序。
- 弹窗支持键盘与点击遮罩关闭；尊重减少动画偏好。
