  and MUST NOT consume, block on, or pre-build the DIR-100-C diagnostics channel (a sibling split
  child, separately dispatched). The Proposal is explicit: "No dependencies within the split."

  must keep returning the same `GatesConfig` empty/partial shape and must never throw on any malformed
  `gates:` value (AC #3). A malformed config still yields the empty shape; the diagnostics are
  additive.

  MUST come before any iteration, and it emits ZERO diagnostics (AC #3 matches current graceful-empty).
