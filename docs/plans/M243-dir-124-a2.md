  - Exports: `runWorkflowReplay(casePath: string): ReplayResult`, `runAllWorkflowReplays(fixturesDir: string): ReplayResult[]`

    4. Evaluate each assertion's `check` predicate against the observed state vector. Predicates: `stageOrderedBefore(events, A, B)`, `agentCountForStage(events, stage, count)`, `fieldEquals(events, stage, field, value)`, `outcomeMatches(events, expectedOutcome)`, `hasStage(events, stage)`, `stageSkipped(events, stage)`, `worktreeFieldsPopulated(events, stage)`. Predicate names resolved from `expectations.json` declaratively.
    5. Classify each assertion result by its `classification` (D3 exit codes: normative-fail→1, compat-only-fail→2(stderr), known-defect-pass→info, known-defect-reproduced→info, known-defect-drifted→1).
  - **Purity contract (AC7):** zero `agent()` calls, zero `execFile`/`execSync`, zero `writeFileSync`/`appendFileSync`. Only `fs.readFileSync` on fixture paths and the A1 schema module. Deterministic output.
  - **Edge cases (all fail-closed):** empty fixtures dir → exit 0 "no fixtures found"; missing fixture → `{ok: false, error: 'fixture-not-found'}`; malformed events.jsonl → exit 1 with line number; malformed expectations.json → exit 1; unknown classification → treated as `normative` (fail-safe default); schema version mismatch → exit 1.
