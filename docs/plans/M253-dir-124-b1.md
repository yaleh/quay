## Symbols

Exports/CLI from `run-identity.ts` (both mirrors):

| Symbol | Kind | Description |
|--------|------|-------------|
| `RunIdentity` | TypeScript interface | 16-field typed envelope, versioned from birth (`schemaVersion: "1"`) |
| `mintRunIdentity(input)` | function | The ONE factory; produces the same envelope for width-1 and width-N inputs (only `taskIds` cardinality differs) |
| `serializeIdentity(identity)` | function | Deterministic `JSON.stringify(identity, Object.keys(identity).sort())` — byte-identical for identical identities |
| `toBuildManifestRunIdentity(identity)` | function | Projection → `{milestoneId: candidateId, taskIds, composite: taskIds.length > 1, attempt, sessionId}` for `build-evidence-manifest.ts`'s inline shape, WITHOUT editing that module |
| `main()` | function | CLI dispatcher (sole `process.exit()` owner) |
| `--create '<json>'` | CLI mode | Mint: inputs `{candidateId, taskIds, attempt?, workflowSourcePath, taskFiles, charterFile, planFile, baseCommit?, sessionId?}` → typed `RunIdentity` JSON |
| `--bind-candidate-commit '<identity-json>' <commit>` | CLI mode | Pure immutable re-derivation returning a NEW identity with `candidateCommit` set |
| `--check-candidate-commit '<identity-json>' <observedCommit>` | CLI mode | Exit 0 on match; exit 1 `candidate-commit-moved` on mismatch / `candidate-commit-unbound` if null |
| `--selftest` | CLI mode | Embedded validation; exit 0 all-pass, non-zero + diagnostics JSON otherwise |

`RunIdentity` fields: `schemaVersion`, `runId` (`` `${sessionId}::${candidateId}::${attempt}` ``), `sessionId` (env-derived, DD2), `candidateId`, `taskIds` (width 1 = singleton, N = composite), `attempt` (default 1; journal-monotonic from B3), `baseCommit` (derived `git rev-parse HEAD`, DD3), `candidateCommit` (`null` until bound, DD4), `workflowSourcePath`, `workflowSourceHash` (sha256 of source bytes), `workflowSourceCommit` (`git log -1 --format=%H -- <path>`), `runtimeGeneration` (`sha256(workflowSourceHash).slice(0,12)`, DD5), `taskHash`, `charterHash`, `planHash`, `materialInputHashes` (`{path: sha256}`).

Fail-closed error codes (all exit non-zero with structured JSON): `missing-session-id`, `session-id-conflict`, `base-commit-mismatch`, `base-commit-unresolved`, `invalid-task-ids`, `material-input-missing`, `workflow-source-missing`, `mirror-drift`, `candidate-commit-unbound`, `candidate-commit-moved`.
