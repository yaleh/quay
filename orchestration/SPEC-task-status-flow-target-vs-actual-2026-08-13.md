## 1. 目标模式（全部来自人 2026-08-13 的裁定，逐条有出处）

```
                    ┌──────────────────────────────────────────────┐
   todo ────────────┤ outer：① 修不合格（补产物/改 Touches/补 self-touch）
                    │        ② 尽力晋，【不考虑优先级】             │

                                      ↓
                   ready ──[ inner：语义选择 + 派发（按倾向，非机制排序）]──> 在飞
                                      ↓
                    per-task 全量在自有 worktree 跑绿 ──> A6 fan-in ──> done
                                      ↑                                   │
                    条件变质时 ready ─┘（双向重评，当前降观察项）          ↓
                                                              翻 done（归属见差异①）
```

**裁定出处**：
- 「todo → ready 的推进，由 outer 执行，**不考虑优先级** —— outer 应尽力把所有可能推进的 todo task 推进 ready」

- 「**就应该是 outer 修**」（指不合格的 todo）
- 「per-task 必须跑 suite 测试」＋ AC4 停全局轮已执行 ⇒ **per-task 绿是唯一认证**
