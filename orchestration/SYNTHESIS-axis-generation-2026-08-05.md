# 这套机制能不能没有人也演进——按证据测,不按印象

**日期**:2026-08-05(管理者)
**触发**:人更正了目标本身——「我做的无非是把这个自举过程启动起来以及偶尔引导演进方向,
显然我希望这套机制没有我也能演进」。⇒ **产品化是手段,自举演进才是目的。**
**性质**:测量 + 一个可证伪的判据 + 一个可检验的生成器。**立案与否由外层判断。**

---

## 1. 我预设的结论被自己的数据推翻了

我原本准备写的是:「机器只发现机械缺陷,结构性的全靠人」。**实测不支持。**

```
tasks/gap-*.md 总数:200
任务体内可归因来源的:人 20 / 机器 36
```

机器发现的数量是人的 1.8 倍。而且其中**确有新增维度的**,至少 7 条:

| 机器自己开出的新维度 | 它加的轴 |
|---|---|
| `...spawn-count-criterion-was-wall-clock-and-that-is-the-wrong-axis-for-concurrency` | 墙钟 → 并发 |
| `...no-resource-awareness-heavy-ops-run-blind` | 资源 |
| `...checkers-have-never-been-shown-to-fail` | 判据自身的有效性(元层) |
| `...cold-start-needs-a-human-to-dictate-eight-steps` | 自主度 |
| `...install-rewrites-files-so-upgrade-cannot-tell-who-changed-them` | 升级/溯源 |
| `...drive-text-carries-data-not-behavior` | 驱动语义 |
| `...eighty-one-instruments-behind-remembered-paths-and-no-entry-point` | 可发现性 |

**⇒ 「机器不能开新维度」是假的。它能,约占其发现的 20%。**

---

## 2. 真正的差别不是**能不能**,是**什么时候**

把那 7 条逐条回看,它们有一个共同点:**全部产生于「用的时候被硌了一下」**——
判据跑出矛盾、脚本慢到没法用、路径记不住、装完发现认不出谁改的。

**人开的 20 条不需要疼。** `trend-criteria` 立案时没有任何东西在报警;
`productize-the-manager-layer` 立案时三层跑得好好的;`complete-delivery-surface` 立案时冷启动是通的。

> **机器的维度生成是摩擦的副产品;人的维度生成不需要摩擦。**

这决定了没有人的时候会怎样退化——**不是停止发现,是渐近**:
把所有硌人的地方修完,然后在**从未打开过的每一个维度上报绿**。
今晚已有实例:套件耗时、每测试成本、晋级速率、就绪池水位——
**每一条都在恶化,每一条都没有报警,全部靠人问出来。**

---

## 3. 可证伪的判据(替换我原来那条含糊的 AC9)

**不是**「它能不能发现缺陷」——今晚 36 条,这个已经证明了。
**是**:

> **它有没有在某个维度**还没有疼的时候**打开过那个维度?**

当前计数:**0**。那 7 条全部是事后(post-friction)。

这条判据可以每晚机械地统计:新立案任务里,有几条在立案时**不存在**触发它的失败/告警/矛盾。

---

## 4. 一个可检验的生成器(不是原则,是能跑的问句)

摩擦不可调度,但**「这条判据在什么范围上成立」是可以逐条问的**。
对系统里每一条常驻判据,问:

> **它量化的是哪一个范围?时间 / 作用域 / 层 / 实例 / 成本?
> 如果答案是「眼前这一个」,那就有一根没打开的轴。**

**检验方式:它能不能反推出人今晚给的那几条?**

| 人给的 | 生成器问句 | 是否反推得出 |
|---|---|---|
| 判据全是点状,缺趋势型 | 「绿了吗」量化的是**哪段时间**?⇒ 眼前这一次 | ✅ |
| 红窗停派应按闸门作用域 | 「红就停」量化的是**哪个作用域**?⇒ 全局一刀切 | ✅ |
| 交付两层却跑三层 | 循环文档覆盖**哪几层**?⇒ 眼前这两层 | ✅ |
| 分叉基线与汇入点应拆开 | `master` 承担**哪几个角色**?⇒ 压在一个 ref 上 | ✅ |
| 量化停止条件没有作用域 | ——(这条本身就是同一问句) | ✅ |

**5/5 反推成功。** ⇒ 这不是事后归纳的漂亮话,是一个有预测力的生成器。
它也解释了为什么这类缺口成簇出现:**我们总是为眼前这一例造判据,从不问它该在多大范围上成立。**

---

## 5. 与已立案的关系

`gap-quality-criteria-are-point-in-time-no-trend-criteria` 是本生成器在**时间轴**上的一个实例;
`gap-quantified-stop-conditions-have-no-scope` 是它在**作用域轴**上的一个实例。
⇒ **两条已立案的任务是同一个生成器的两个投影。** 建议按这个关系归并,
而不是继续一条一条捡实例——捡实例的速度受限于人在场。
