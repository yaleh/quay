# test-isolation-violations.txt — known violations of the TEST-ISOLATION CONTRACT
# (gap-test-isolation-contract-is-unwritten + gap-tests-never-clean-up-their-tmpdirs +
# gap-r1-cannot-see-tests-writing-into-the-live-task-store).
#
# POLICY: a test must never touch something it does not exclusively own. Seven rules
# (details in docs/analysis/test-isolation-contract.md, sourced from the three
# isolation-green/suite-red failures of 2026-08-02/03 + the 2026-08-03 /tmp leak):
#   R1 fixed-path-write             write only to per-run-unique paths (mkdtemp / os.tmpdir()),
#                                   never a fixed __dirname/.tmp-* path under the shared checkout
#                                   (relation-sync's 8-copy 7/8 crash is the type specimen).
#   R2 shared-build-artifact-write  never rebuild/overwrite the SHARED build artifacts
#                                   (packages/<pkg>/dist/, plugin/vendor/) — build to a temp tree
#                                   (M136, three rounds).
#   R3 spawns-test-sh               never spawn the whole scripts/test.sh runner inside the suite
#                                   (AC11's 60s-budget nested run).
#   R4 process-exit-1               a hand-rolled harness's failure path must use process.exitCode,
#                                   never process.exit(1) (can drop async stderr writes under a
#                                   POSIX pipe — relation-sync's silent suite-red).
#   R5 (doc-only)                   never depend on the running repo's git history (shallow clone
#                                   must stay green) — documented in the contract, no scanner rule.
#   R6 mkdtemp-no-cleanup           a file that mkdtemp()s leaks a tmpdir per run when the created
#                                   dir is not removed. Partial-cleanup-aware since
#                                   gap-tmp-leak-is-live-r6-absolves-a-file-for-one-cleanup-call
#                                   (2026-08-03): every variable-assigned mkdtemp result must be
#                                   covered by a cleanup path (direct rmSync/rm/after/finally, a
#                                   carrier-array + after-loop, or a helper-return captured into a
#                                   cleaned variable). NEVER matches /tmp/claude-* (session data)
#                                   prefixes (AC6); the quay-wt-* worktree exemption was removed
#                                   (worktrees are git worktree add at loop.worktree_root, never
#                                   mkdtemp'd — gap-the-shipped-tick-doc...).
#   R7 live-data-dir-write          never WRITE into the repo's LIVE product-data directories
#                                   (tasks/, .quay/, .workflow-events/, adr/) via a NON-per-run-
#                                   unique root (process.cwd()/__dirname/import.meta — the shared
#                                   checkout). gap-r1-cannot-see-tests-writing-into-the-live-task-
#                                   store (2026-08-03): R1 required `__dirname` AND a `.tmp`
#                                   literal together, so `path.join(process.cwd(), "tasks",
#                                   "M-FAKE-…md")` satisfied NEITHER and a test wrote a fixture into
#                                   the REAL tasks/ (swept into a commit by a windowed git add -A).
#                                   Writing under a per-run-unique root (mkdtemp/os.tmpdir/makeTmp)
#                                   is the SAFE pattern and never reports.
#   R8 shared-root-mkdtemp          never mkdtemp() with a root that resolves INTO THE SHARED
#                                   CHECKOUT (REPO_ROOT/repoRoot/__dirname/import.meta/process.cwd()
#                                   or a variable derived from one) — os.tmpdir() only.
#                                   gap-mkdtemp-rooted-in-the-shared-checkout-dirties-the-tree
#                                   (2026-08-03): ts-typecheck-gate.test.mjs mkdtemp'd at
#                                   path.join(REPO_ROOT, ".quay-tmp-test-") every run, dirtying the
#                                   working tree (readiness clean-tree false-fail) and swept into
#                                   git add -A. Invisible to R1 (`.quay-tmp` is dot-quay-tmp, not
#                                   dot-tmp) and R7 (repo root is not a LIVE dir) — fell exactly
#                                   BETWEEN them. INVARIANT: per-run-unique is NECESSARY, not
#                                   SUFFICIENT — the mkdtemp root must ALSO not be the shared
#                                   checkout. os.tmpdir()/makeTmp-derived roots never report.
#
