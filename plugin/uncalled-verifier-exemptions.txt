# uncalled-verifier-exemptions.txt — shrink-only exemption list for the uncalled-verifier check
# (tasks/gap-shipped-verifiers-have-no-callers-and-mentions-defeat-the-check).
#
# POLICY: every verifier in plugin/scripts/*.{sh,ts,mjs} must have an EXECUTION-TYPE call site
# (loop doc / gate / CI job / script), where the following do NOT count as call sites: (a) the file
# itself, (b) its own plugin/test/<same-name>.test.mjs, (c) pure description strings
# (capability-catalog.sh entries, prose docs, task bodies). A verifier with zero execution call
# sites is SHIPPED-BUT-UNCALLED — it must be WIRED (given a real call site) or EXEMPTED here with a
# reason. This list records the KNOWN-INTENTIONAL uncalled verifiers: manual-only report tools,
# retired/dormant libraries, exp5-legacy tools, and test-only data modules.
#
# The registry of this class (DoD): the wired instances are verify-delivery-surface.ts (wired into
# scripts/test.sh's run_static_checks by this task, AC3) and uncalled-verifier-check.ts (the check
# itself, wired into run_static_checks). periodic-push-backup.sh gained its real call site via
# sync-lag-check.sh (tasks/gap-cross-machine-sync-has-no-mechanism-only-manual-pushes). measure-suite
# .mjs / measure-suite-reporter.mjs are cross-referenced to
# tasks/gap-single-file-test-duration-trend-unwatched. trend-check.ts is cross-referenced to the
# quality-trend family. The remaining entries below are the current known-intentional census.
#
# RATCHET (AC4): this list can ONLY get SHORTER. The check fails if a file is ADDED to it. There is
# no mechanical way to exempt a NEWLY-uncalled verifier — wire it instead. To remove an entry, give
# that verifier a real call site FIRST, then delete its line here — the check then fails on the
# stale entry until it is removed, which is the nudge that makes "wire it, then shrink the list"
# the default path (same discipline as test-framework-policy-exemptions.txt).
#
# baseline-count: 32
# `# baseline-count: <n>` is the MACHINE-READABLE RATCHET CEILING parsed by the check — the list can
# NEVER exceed this many entries, even at a clean commit (commit-surviving AC4). It is permanent:
# it stays 32 as entries are removed (the list only shrinks below it).
