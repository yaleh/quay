Infrastructure, not a DoD clause (see DIR-017), but a high-priority prerequisite for reliable driving. This session the autonomous loop and the human both committed to `master` in the same working tree, producing: a wholesale auto-take conflict resolution that silently discarded one side's content (989e0cd, per DIR-013); a conflicted in-progress merge in the shared index that twice blocked human commits and swept human files into the loop's merge index (had to decouple by hand + poll for a clean window); and a boundary reconcile that missed regenerating DIR-013's projection. Requested: (1) run the OUTER loop in its own branch/worktree, not committing directly to human-shared master; (2) human steering merges in deliberately at a boundary (define direction/cadence), never by racing; (3) no silent content-dropping merges — record a reconciliation note, and let DIR-017's standing checks catch conflict-free-but-inconsistent auto-merges (the M18 OUTER-LOOP.md case); (4) keep it minimal/mechanically-checkable. Value type risk/option + governance-integrity, Δv̂≈0, high priority (every future human steering session races the loop until this lands).
