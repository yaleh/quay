## Proposal
On the supervised restart of exp5, the loop MUST prioritize the "close the observe-and-enforce loop" cluster BEFORE the foundational D1 — because until convergence is measurable and decisions are enforced, the loop runs blind and its ADRs stay soft.

## Finding
Audit (2026-07-20) at the restart line: the METHOD layer is crystallized (schema-validator, DoD Clauses 0–9, `quay gate`, split-or-commit Clause 9, test-floor, line-budget, impl-row, vmeta-lag — all runnable, fixture-pinned, golden-replay-verified, firing in ABSORB). BUT the loop is NOT yet closed on two things: (1) **convergence is not observable** — L_D/L_G/L_S are dark (only L_T + half L_C lit); we cannot quantitatively SEE whether we are crystallizing. (2) **decisions (ADRs) are un-wired** — most `enforcement` stubs are `(E3, deferred)`; B7 exists but is not in the ABSORB gate sequence; only `dod/acceptance/impl-row/line-budget` are registered gates (no `vmeta-lag`/`audit`/`adr-<id>`). By ADR-004/ADR-011, un-wired = soft = will drift. If the loop restarts onto D1 (foundational but neither observing nor enforcing), the first several cycles will show progress without showing convergence.

## Requested action
For the first restart WINDOW (the first ~4–5 milestones), SELECT prioritizes — in this order — over any other candidate INCLUDING D1:
1. **exp5-M-CRYST-G1** — implements ADR-007: light the dark axes L_D (code:doc + archguard) / L_G (archguard cycles/god-packages/dup-abstractions) / L_S (mutation/property). Makes convergence MEASURABLE.
2. **exp5-M-CRYST-E3** — adr-as-contract: wire accepted ADRs as `adr-<id>` engine gates (GateEvent = the "honored" ledger). Makes decisions ENFORCED (starts with ADR-001→B7).
3. **exp5-M-DIR022-REMAINING-GATES** — register vmeta-lag/audit/escrow/test-floor as named engine gates + prove multi-gate ABSORB on a real milestone. Makes `quay gate-log` the REAL audit trail (unblocks DIR-024).
4. **exp5-M-CRYST-INV** (gate half) — turn ADR-011 (enforcement-lands-with-design) from prose into a hard gate.
THEN **exp5-M-CRYST-D1** (foundational; unblocks D2/D3-§9/E2). The `human-steered` fence (D2/D3/F1) still applies. This is a first-window steering directive, not a permanent re-ranking — after the window the normal value-typed SELECT resumes.
