## Proposal
Harden the outer loop's main-tree git hygiene WITHOUT reversing DIR-027 (the loop still runs directly on `master` in the main working tree). The goal: the main tree is CLEAN between the loop's atomic per-step commits and carries no scratch, so out-of-band human/steering work can slot in during the between-step gaps instead of going through a private worktree and racing a transient clean window. (This is Tier 1; Tier 2 — moving the outer loop into a persistent driver worktree with ff-only boundary publishes — is a separate, bigger decision for its own directive.)

## Finding
DIR-027 puts the outer loop on `master` in the main directory (SELECT dispositions, charter, plan docs, dashboard, ABSORB, and the iteration-worktree merge all land here; only the inner iteration BUILD is in `**/worktrees/`). In practice the main tree is therefore **continuously dirty mid-milestone**, from two causes observed this session: (a) **un-gitignored scratch** — the L_S mutation proxy left `packages/quay/src/gate/registry.js.l-s-backup` untracked in the main tree; (b) **uncommitted outer bookkeeping** sitting between the loop's commits. Consequence: landing ADR-012 required a private worktree + a poll-and-merge, and two direct attempts were raced away by the loop. This makes out-of-band steering a second-class, racy operation — the exact friction Tier 1 removes.

## Requested action
1. **No scratch in the main tree.** Every scratch/temp/tool-output artifact the loop's own steps generate is either gitignored OR generated only inside a worktree — never left untracked on `master`. Immediately fix the known leak class (`*.l-s-backup` and any mutation/tool backups). The shipped `scripts/tree-hygiene-check.sh` is the mechanical enforcer (grep-lists known scratch patterns left untracked).
2. **Clean between steps.** The outer loop commits its bookkeeping ATOMICALLY per step (SELECT / charter / ABSORB each their own commit), so `git status` on `master` is clean between steps — a reliable slot-in gap. Wire this expectation into `OUTER-LOOP.md` (a per-step "commit, leaving the tree clean" close-out).
3. **Wire the check.** Register `tree-hygiene-check.sh` into the ABSORB gate set and/or `restart-readiness-check.sh` so a scratch leak HARD-fails, not drifts (ADR-011 — the rule ships with its enforcement; the starter check is included by this DIR).

## Acceptance Criteria
- [ ] `scripts/tree-hygiene-check.sh` exits 0 on a clean tree and exit 1 when a scratch file (`*.l-s-backup`/`*.bak`/`*.tmp`/…) is left untracked; it never flags ordinary new source/task files. (Shipped with this DIR.)
- [ ] The known scratch patterns are gitignored (e.g. `*.l-s-backup`); `git status` shows no untracked scratch after a real milestone's L_S run — `tree-hygiene-check.sh` green on the live tree.
- [ ] `OUTER-LOOP.md` states the per-step "commit → tree clean" close-out; a real milestone leaves the main tree clean between SELECT / charter / ABSORB.
- [ ] `tree-hygiene-check.sh` is wired into ABSORB and/or `restart-readiness-check.sh`.
## Definition of Done
References the standard inherited-core DoD clauses; the bar is REAL LANDING, not artifacts:
- [ ] On a REAL milestone, the main tree is clean between the loop's atomic commits and carries no un-gitignored scratch — verifiable by `tree-hygiene-check.sh` green on the live tree at a between-steps window.
- [ ] An out-of-band edit slots into a between-steps clean window WITHOUT a private worktree or the poll-and-race we hit landing ADR-012.
- [ ] The hygiene check is wired (not prose-only); DIR-027 (loop on master) is preserved, not reversed.

## Human verification when exp5 marks this DIR done
1. During a real milestone, run `scripts/tree-hygiene-check.sh` at a moment between the loop's commits — is it green (no scratch, tree clean)?
2. `grep -n 'l-s-backup\|backup' .gitignore` — are the loop's scratch patterns ignored?
3. `grep -n 'tree-hygiene-check' experiments/quay-perpetual-stream/OUTER-LOOP.md experiments/quay-perpetual-stream/scripts/restart-readiness-check.sh` — is it wired?
4. If only the check file exists but the loop still leaves scratch / an uncommitted mid-milestone tree, it is NOT landed — send back.
