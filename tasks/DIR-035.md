## Proposal
Steer the loop to execute the delivery-boundary separation decided in `adr/ADR-013`, so quay (product + methodology kit) becomes genuinely deliverable and reusable — separated, packaged, and VALIDATED. The substance (the three standing rules) lives in ADR-013; this directive is the loop-facing steering + the real-landing bar. The acceptance meter is one command: `bash packages/quay/test/delivery-standalone-smoke.sh` going from 5 RED to 0.

## Finding
A `delivery-standalone-smoke` (shipped with this directive) packs the product as npm would deliver it into a workspace with no `experiments/` dir and finds **5 RED delivery blockers** (full detail in ADR-013 Context): the product does not stand alone — a bare `npm install quay` fails even `--help` because the gate registry imports `../../../quay-native/...` (a Provider-ABI violation) and hardcodes 5 `experiments/quay-perpetual-stream/scripts/*.sh` gate paths + `ADR_GATE_IDS=["ADR-001"]`. The three layers (current-experiment / this-project / delivery-reuse) are entangled, not packaged.

## Requested action
Land the ADR-013 separation in tracked increments, each moving the smoke count down, never up:
1. **ABI, not file paths (R2/R3/R4 — the architecture violation, do first).** Remove Core's `../../../quay-native/{adr-store,document-store,contract-validator}` imports in `registry.js`; reach those capabilities via the Provider ABI, or make them a declared dependency on a Core-owned/shared package. After this, `quay --help` and `gate --list` load standalone.
2. **Data-driven gate set (R1/R5).** Move the `it0-*`/`vmeta-lag`/`audit-independence`/`dogfood-evidence` built-ins out of the product's default registry into exp5's own `.quay` config; product ships engine + factories only; gate check commands come from workspace data (ADR/doc `enforcement:` field or `.quay/gates.yml`), like the `adr-<id>` gate already does.
3. **Experiment state ≠ product data.** Delivered product ships an empty/minimal example store, not the 267-file multi-experiment backlog; single-source the methodology kit (stop the per-experiment `inherited-core` duplication); experiment dirs keep only instance state + a kit-version pin.
4. **Wire the gate.** Once green, register `delivery-standalone-smoke` as a named delivery conformance gate (ADR-011: the rule ships with its enforcement — the smoke already exists; wiring it is the closing step).

## Acceptance Criteria
- [ ] `bash packages/quay/test/delivery-standalone-smoke.sh` exits 0 (was 5 RED) — the product stands alone: `npm install quay` into a fresh workspace with no `experiments/` dir loads `--help` + `gate --list` and shows no experiment/cross-package references in delivered files.
- [ ] `grep -rnE 'experiments/|\.\./\.\./\.\./quay-(native|github)' packages/quay/src packages/quay/bin` returns nothing (no experiment paths, no cross-package relative imports in the product).
- [ ] The default gate registry contains no hardcoded `experiments/**` path and no hardcoded experiment ADR id; exp5's gates are sourced from exp5 workspace config; a fresh non-exp5 workspace's `gate --list` shows only engine built-ins + that workspace's own data-driven gates.
- [ ] The delivered product ships no experiment backlog (a delivered `tasks/`/example store is empty or a minimal documented sample), and the methodology kit is single-sourced (no duplicated `inherited-core` per experiment).

## Definition of Done
References the standard inherited-core DoD clauses; the bar is REAL LANDING, not artifacts. Necessary-but-not-sufficient: the smoke existing / one increment green. Done ONLY when:
- [ ] A REAL npm-delivered product (`npm pack` → fresh install, no `experiments/`) passes the standalone-smoke 0 RED, AND at least the **deployment-level** transfer is demonstrated once on a REAL foreign repo (archguard or meta-cc): quay drives a real task there through the board + a gate via the Provider ABI — proving the product transfers off this repo, with the real command output pasted in the ABSORB entry.
- [ ] The Provider-ABI violation is gone (Core no longer imports a sibling package by path); the gate set is data-driven; behavior preserved on quay's own suite (golden-diff/selfchecks green).
- [ ] `delivery-standalone-smoke` is wired as a delivery conformance gate; ADR-013's boundary is enforced mechanically, not prose-only.
