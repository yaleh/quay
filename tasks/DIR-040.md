## Proposal
The ingredients for a quay Claude Code plugin ALREADY exist but ship as loose npm files, not an installable plugin: quay Core has an `mcp` subcommand (the server, proxying to the enabled provider), quay-native ships `skills/author` + `skills/execute` (SKILL.md), and `/quay-directive` exists — BUT there is NO plugin manifest (no `.claude-plugin/plugin.json`, no commands dir, no marketplace). So onboarding a foreign project means a manual `claude mcp add quay -- quay mcp`, NO skills come along, and `/quay-directive` is HARDCODED to the exp5 layout (it lists `experiments/*/`, runs `experiments/quay-perpetual-stream/scripts/task-schema-check.mjs`, touches `experiments/<X>/.halt`) so it does not work in a non-exp5 workspace like archguard.

Package quay as a **Claude Code plugin** that bundles: (1) the quay MCP server (`quay mcp`); (2) the existing author/execute skills; (3) a **WORKSPACE-PORTABLE directive skill** — de-hardcode it from the exp5 experiment layout, SHIP its schema-check with the plugin (not a reference to `experiments/**`), generalize "the active experiment" to "this workspace's task store"; (4) a plugin manifest + slash command(s) so `claude plugin install` (or a marketplace entry) gives any project quay's task tools + authoring skills in ONE step. Pure in-repo quay packaging → **LOOP-EXECUTABLE** (`milestone-candidate`, NOT `human-steered`).

**Scope line:** this packages what EXISTS + makes the directive skill portable (the DISTRIBUTION surface). The full OUTER-LOOP continuous-development methodology port (the loop itself + the it0 DoD meta-enforcer ported to a foreign TS/vitest stack) stays [[DIR-036-B]]. DIR-040 is how you INSTALL quay's authoring toolkit; DIR-036-B is running the loop.

Value: **capability-growth** (a distribution/packaging surface) — and it's the enabler that makes "query tasks in Claude Code" and "create a directive" work PORTABLY in any project, not just quay's own repo. Feeds [[DIR-038]]-C's outward-VT term (a real external plugin install is outward value). Same class as [[DIR-037]] (ENOBUFS): surfaced by operating quay in archguard ([[DIR-036-A]]).
