## Proposal
Add a continuous EXTERNAL-dogfooding / discovery channel to the loop: a standing loop-driver routine that exercises quay from outside the experiment layer on a recurring cadence, filing evidence-backed findings as directive tasks.

## Finding
All product DIRs (DIR-037/039/040/041/042) came from manual human dogfooding/auditing, not from the autonomous loop's discovery engine. The loop has no standing external-dogfooding channel — it only discovers gaps when a human manually exercises the product.

## Requested action
Create a standing external-dogfooding routine in the loop-driver that exercises quay against a real foreign workspace (archguard) on a per-N-iterations cadence, filing real gaps as directive tasks.

## Mechanism — tmux remote-drive
The "how" for driving a foreign workspace's Claude Code session autonomously is **[[ADR-016]]** (TMUX
REMOTE-DRIVE) — the canonical single source. In brief: drive with `send-keys` (reliable = 3 separate
calls `C-u` → text → `Enter`), verify from the filesystem/meta-cc (never parse the TUI), under
single-driver hygiene; prereqs `DISABLE_ALTERNATE_SCREEN`/`DISABLE_MOUSE` + `bypassPermissions` + a
reachable tmux session. Proven driving the [[DIR-051]] real routine-fire on archguard (2026-07-22). Full
contract + rejected alternatives live in ADR-016 — NOT duplicated here (single-source, ADR-004).

## Acceptance Criteria
- [x] Routine fires on a configurable cadence (every N iterations or on checkpoint).
- [x] Routine exercises real product API against a foreign workspace.
- [x] Findings filed as `label:directive` tasks with real evidence.
- [x] The routine drives the foreign workspace via the tmux remote-drive contract above (3-step `send-keys`; result read from filesystem/meta-cc, not the TUI) under single-driver hygiene — demonstrated by a real remote-driven fire.

## Definition of Done
References the standard inherited-core DoD clauses; the bar is REAL LANDING, not artifacts:
- [ ] At least one real dogfooding routine fire produces at least one real directive task.
- [ ] Routine is configurable via `.quay/loop.yml` (DIR-051 routine track).
