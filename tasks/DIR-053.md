## Proposal
Light the `L_G`/`L_D` dark axes (ADR-006/007) on quay's OWN architecture continuously, and turn the
readings into filed improvement tasks — a standing routine on the [[DIR-051]] mechanism. ADR-007 names
archguard as the `L_G`/`L_D` instrument, but archguard cannot read JavaScript (ADR-012's whole
motivation), so quay's architecture is currently un-measured (G1/M41 hit exactly this wall). Two paths,
both usable as a routine:
- **now (interim, ADR-012):** JS-native proxies — `madge`/`dependency-cruiser` for dependency cycles &
  god-packages/fan-in, `jscpd` for duplication/reinvented abstractions — run on `packages/**`.
- **post-[[exp5-M-TS-MIGRATION]]:** archguard itself, reading the migrated TS (the observability upgrade
  ADR-012 targets). The routine's `dispatch` swaps proxy→archguard when TS lands; the config is stable.

```yaml
routines:
  - name: architecture-analysis
    trigger: on(checkpoint)        # at each checkpoint (or every(N))
    dispatch: archguard-or-proxy   # archguard if TS-ready, else madge/dependency-cruiser/jscpd
    files: tasks
    gate: quality-dedup-rate
```

The routine reads the L_G/L_D signal, and files a task for each ACTIONABLE finding (a new dependency
cycle, a god-package crossing a fan-in threshold, a duplicated abstraction) with the tool output as
evidence. This makes the ADR-007 dark axes a STANDING observation, not a one-off, and — like DIR-052 —
is exactly the outward instrument-correction value the DIR-038 re-based ruler scores.

**Guardrails:** FILE-only (files improvement tasks; the SELECT track drives fixes under gates/audit); a
finding must carry the real tool output (the actual madge cycle / jscpd clone report), not an assertion;
the quality/dedup/rate gate stops re-filing the same known cycle every checkpoint.

Pure in-repo capability, rides DIR-051; the interim-proxy path unblocks it BEFORE the TS migration →
**LOOP-EXECUTABLE** (`milestone-candidate`).

**Out of scope:** the routine MECHANISM (DIR-051); the TS migration itself ([[exp5-M-TS-MIGRATION]] —
this routine consumes its output, does not perform it); auto-fixing architecture findings (FILE only).
