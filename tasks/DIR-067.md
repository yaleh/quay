## Proposal

OUTER-LOOP.md (627 lines) encodes two fundamentally different kinds of work:

| Steps | Kind | Lines | % |
|---|---|---|---|
| 0–3 (DRAIN, SELECT, VALUE HYPOTHESIS, AUTHOR CHARTER) | **Judgment-heavy** — value-typed ledger, explore/exploit cadence, D-quota, charter authoring | ~178 | 28% |
| 4–7 (it0 checks, dispatch inner, ABSORB gates, dashboard update) | **Deterministic orchestration** — 21 script calls, 2 subagent dispatches, git ops, parallel gate checks | **356** | **57%** |
| 8 (CHECKPOINT) | Conditional, lightweight | ~12 | 2% |

Steps 4–7 are currently encoded as prose instructions that Claude interprets turn-by-turn. Session analysis (a8cd3b43, M127–M134, 2026-07-23) quantifies the overhead:

- **~50–60 reasoning turns per milestone** consumed by the prose → tool-call → read-output → decide-next loop
- **~50–60 tool calls per milestone** (predominantly Bash script runs + git ops)
- **~50–70K tokens per milestone** of orchestrator context consumed by prose + intermediate results
- **3 REFUTED audit verdicts** (M124/M129/M130) traced to mechanical implementation errors (path mismatches, incomplete check logic, tautological tests) — all caught by adversarial audit, not prevented by prose precision

Claude Code's dynamic workflow system (`.claude/workflows/`) supports deterministic subagent orchestration with `agent()`, `pipeline()`, `parallel()`, `phase()`, structured output (`schema`), and run resumability — but is NOT supported inside plugins (plugin manifest schema has no `workflows` key). The `loop-driver` plugin skill is a deliverable and is not in scope for this migration.

The proposal: author a `.claude/workflows/execute-milestone.js` that encodes OUTER-LOOP steps 4–7 as a deterministic workflow script. OUTER-LOOP.md reduces to steps 0–3 + step 8 + a single invocation of the saved workflow command (`/execute-milestone`). The workflow takes `{taskId, charterFile, absorbEntryFile}` from SELECT (step 1) and runs the full execution pipeline deterministically.

This migration IS a subtractive, behavior-preserving refactor: the prose being replaced is the *same* instructions recoded as code. The experimental value is measuring whether deterministic orchestration reduces audit refutations and improves loop resilience (resume after crash, parallel gate checks).

Key constraint (confirmed by reading Claude Code docs + verifying plugin manifest schema): the workflow script lives in `.claude/workflows/` (project-level, version-controlled), NOT in the `quay` plugin. The plugin continues to deliver judgment skills (quay-directive, author), MCP configs, and agents — exactly as it does today.

## Finding
Search of project session history (meta-cc, 2026-07-22–07-24, 17 sessions):

1. **No prior `ultracode` usage.** The project has never used Claude Code's dynamic workflow keyword or `.claude/workflows/`. ADR-009 ("Drive development via background Claude Code workflows at milestone granularity") defines the *concept* but not the mechanics.

2. **Plugin ≠ workflow confirmed.** Plugin manifest schema (`.claude-plugin/plugin.json`) supports `skills/`, `commands/`, `agents/`, `hooks/`, `.mcp.json`, `monitors/` — NOT `workflows/`. The project's `loop-driver` plugin skill is prose-driven orchestration, not a deterministic workflow script.

3. **Prose execution produces preventable errors.** M129 implementer wrote `check()` that only validated manifest schema without parsing `release.yml`; M130 had path mismatches (`reference/` vs `prompts/`) and grep pattern errors; M124 had tautological tests. All three were caught by adversarial audit — the prose didn't prevent them; the audit caught them in a 2-pass fix cycle.

4. **Session restart frequency.** The loop driver session (a8cd3b43) was restarted at least 8 times over ~6 hours — each restart re-reads the full OUTER-LOOP prose and loses intermediate execution state. Workflow resume would preserve completed phase results.

5. **Quantitative overhead confirmed.** Per milestone, steps 4–7 consume ~50–60 orchestrator turns, ~50–60 tool calls, and ~50–70K tokens of orchestrator context (out of ~186K/milestone total).
