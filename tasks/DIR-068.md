## Finding

`quay serve` currently hardcodes binding to `0.0.0.0` (all interfaces) with no way to restrict it to a specific interface. Evidence:

1. **`packages/quay/src/serve.ts:90`**: `server.listen(port, "0.0.0.0", ...)` — host is hardcoded.
2. **`StartServerOptions` interface (line 32-34)**: only `port`, no `host`.
3. **CLI usage (`packages/quay/bin/quay.ts:314`)**: `quay serve [--port <port>]` — no `--host`.

There are legitimate reasons to bind to a specific interface:
- **Security**: bind to `127.0.0.1` when only local access is needed (e.g., development, or when proxied behind nginx/Caddy on the same host).
- **Tailscale / VPN**: bind to a specific Tailscale IP (`100.x.x.x`) to serve only on the private mesh, not on the host's public-facing interfaces.
- **Multi-instance**: running separate quay serve instances on different interfaces.

## Requested action

Add a `--host` option to `quay serve` that passes through to `StartServerOptions` and `server.listen()`. Default remains `0.0.0.0` (current behavior, backward-compatible).

Scope:
1. Add `host?: string` to `StartServerOptions` in `packages/quay/src/serve.ts`.
2. Thread `host` into `server.listen(port, host, ...)`, defaulting to `"0.0.0.0"` when not provided.
3. Add `--host <host>` CLI flag in `packages/quay/bin/quay.ts` serve command, parsed and passed to `startServer({ port, host })`.
4. Update help text: `quay serve [--port <port>] [--host <host>]`.
5. Update the log line to reflect the actual host bound (currently always prints `0.0.0.0`; should print the configured host).

## Acceptance Criteria

- [ ] `quay serve --host 127.0.0.1` binds only to localhost (verify: `curl http://127.0.0.1:<port>` works, `curl http://<other-ip>:<port>` from another host fails).
- [ ] `quay serve --host 100.x.x.x` binds only to the specified Tailscale IP.
- [ ] `quay serve` (no --host) continues to bind `0.0.0.0` (backward-compatible default).
- [ ] `quay serve --help` shows `[--host <host>]`.
- [ ] Log line reflects the actual host: `listening on http://<host>:<port>`.
- [ ] Existing serve tests pass: `node --test packages/quay/test/serve.test.mjs`.
