## Finding

Meta-cc analysis: 7 of 9 Edit errors (78%) are "String to replace not found in file." The model constructs `old_string` from stale read context -- the file changed between read and edit (parallel agent, or model edited it in prior turn). No freshness gate before Edit.

## Proposal

Add a pre-Edit freshness-check discipline: before constructing `old_string`, re-read the target region to confirm the string still matches. Or add a gate script that validates Edit operations against current file state.
