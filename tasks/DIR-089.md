## Finding

Meta-cc analysis: 4 identical `JSONDecodeError: Expecting value: line 1 column 1 (char 0)` traces across sessions. The model runs `python3 -c "json.load(open(...))"` on empty/non-JSON output without checking exit codes or non-emptiness first.

## Proposal

Add a reusable `safe_json_parse` shell function that guards against empty output and checks exit codes before parsing. Deploy to all experiment gate scripts that parse JSON.

## Plan

N/A — no docs/plans/*.md reference (instrument-correction, well-defined small scope; inline Plan below is the complete implementation spec).

1. Create `experiments/quay-perpetual-stream/scripts/safe-json-parse.sh` — a sourceable shell library providing:
   - `safe_json_parse <file>` — reads file, checks non-empty, validates JSON, returns parsed content or exits with descriptive error
   - `safe_json_parse_from_stdin` — same but reads from stdin
2. Audit all gate scripts under `experiments/quay-perpetual-stream/scripts/` for JSON parsing patterns (`json.load`, `JSON.parse`, `jq`, `python3 -c.*json`)
3. Replace raw JSON parsing with `safe_json_parse` calls in each identified script
4. Verify each modified script still passes its selfcheck
