## Finding

Meta-cc analysis: 6 identical "Command timed out after 2m 0s" errors. The 2-minute default Bash timeout is insufficient for `npm install`, large git operations, or test suite runs.

## Proposal

Audit long-running Bash calls in the loop and gate scripts. Add explicit `timeout` parameter >=5m where needed.

## Acceptance Criteria

- [ ] All gate scripts invoking `npm install`, `npm test`, or `git clone` have explicit timeout >=5m
- [ ] Meta-cc query for "Command timed out" over 14 days post-fix shows count drops by >=50%
