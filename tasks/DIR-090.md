## Finding

Meta-cc analysis: 6 identical "Command timed out after 2m 0s" errors. The 2-minute default Bash timeout is insufficient for `npm install`, large git operations, or test suite runs.

## Proposal

Audit long-running Bash calls in the loop and gate scripts. Add explicit `timeout` parameter >=5m where needed.

## Plan

N/A — no docs/plans/*.md reference (instrument-correction, well-defined small scope; inline Plan below is the complete implementation spec).

1. Audit all gate scripts under `experiments/quay-perpetual-stream/scripts/` and workflow scripts under `.claude/workflows/` for Bash calls that invoke `npm install`, `npm test`, `git clone`, or other long-running commands without explicit timeout
2. Add explicit `timeout` parameter >=5m (300000ms) to each identified Bash call
3. Verify each modified script still functions correctly
