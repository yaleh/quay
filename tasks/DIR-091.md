## Finding

Meta-cc analysis: `experiments/quay-perpetual-stream/scripts/` contains 50 check/selfcheck scripts (34 checks + 16 selfchecks) sharing common structure: parse args, read task files via YAML frontmatter, run predicate, emit pass/fail. Many duplicate argument parsing, error handling, and output formatting. `.sh`/`.ts` dual variants exist for several checks.

## Proposal

Extract a shared gate-script framework (shell library + TS base class) providing: arg parsing, YAML frontmatter reading, pass/fail output formatting, and selfcheck fixture conventions.

## Acceptance Criteria

- [ ] At least 5 check scripts refactored to use the shared framework
- [ ] Framework includes reusable selfcheck test harness
- [ ] New gate scripts created post-milestone use the framework
- [ ] Line-count reduction ≥200 total across refactored scripts
