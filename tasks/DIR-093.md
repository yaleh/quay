## Finding

The `execute-milestone.js` workflow's Gate phase has a recurring mechanical failure: the `audit-independence-check.sh` gate fails because the Audit agent's session ID is not embedded in the audit artifact or the absorb entry's dispatch record. Impact: M139, M140, M141 all failed at audit-indep gate despite correct implementations — 3 consecutive needs-human milestones burning ~3.3M tokens.

Three structural gaps:
1. Absorb entry created at charter time, before Audit agent runs — can't know future session ID
2. No workflow step between Audit and Gate writes the Audit agent's session ID into the absorb entry
3. audit artifact header lacks embedded session ID for independence corroboration
