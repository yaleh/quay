## Proposal

Ship a distributable quay Core CLI and switch the loop-driver skill to use MCP tools instead of CLI commands. Currently quay can only be used within its own project workspace — external workspaces (archguard, meta-cc) cannot run the loop despite having valid quay-native task boards.

## Finding

Three gaps prevent cross-workspace usage: (1) quay Core CLI has no distributable binary, (2) quay-native CLI points to TS source not compiled JS, (3) loop-driver skill uses CLI commands instead of MCP tools which are already cross-workspace available.

## Requested action

1. Build `packages/quay/dist/quay.js` as distributable binary
2. Fix `quay-native` bin entry to point to compiled JS
3. Update loop-driver skill to use MCP tools
4. Verify cross-workspace on archguard and meta-cc
