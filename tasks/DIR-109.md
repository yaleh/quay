## Finding

ADR-019 (`adr/ADR-019-test-taxonomy-is-structural-in-file-skip-one-canonical-runne.md`) records
that this repo's test taxonomy lives only in duplicated, hand-written prose: the 3 live/conformance
test files (`serve-github.test.mjs`, `provider-abi-conformance.test.mjs`,
`cli-edit-parity-conformance.test.mjs`) are excluded from offline runs by a
`grep -vE 'serve-github|provider-abi-conformance|cli-edit-parity-conformance'` pattern written out
independently in BOTH `CLAUDE.md` and `.github/workflows/ci.yml` — nothing keeps the two copies in
sync. Separately, profiling the full local suite (2026-07-26) found `--test-concurrency=8` is 10.3%
faster than the current default with zero correctness regression across repeated runs (514/514 pass
at concurrency 4/8/16), and nothing currently sets it anywhere.

## Requested action

1. Give each of the 3 live/conformance test files an in-file skip declaration —
   `test(name, {skip: <condition>}, fn)` (or an equivalent file-level early guard) — gated on a
   concrete, checkable condition (env var presence and/or a cheap reachability probe), so the file
   is safe to include in a default, credential-less glob run.
2. Create `scripts/test.sh`: the single canonical invocation script. It owns the test-file glob
   (`packages/*/test/*.test.mjs plugin/test/*.test.mjs`) and defaults to `--test-concurrency=8`.
3. Update `CLAUDE.md`'s Commands section to document `scripts/test.sh` as the canonical entrypoint,
   removing the hand-written glob/grep prose.
4. Update `.github/workflows/ci.yml`'s test step to invoke `scripts/test.sh` instead of its own
   copy of the glob/grep command.

## Acceptance Criteria

- [ ] `scripts/test.sh` exists, is executable, and a no-args run executes the full safe-by-default
  suite (no live/network calls) via `--test-concurrency=8`
- [ ] Each of the 3 live/conformance files declares an in-file skip condition; running
  `scripts/test.sh` with no live credentials produces zero live-network test executions (verify:
  the live-specific tests report `skipped`, not silently absent from the glob)
- [ ] Setting the documented opt-in condition (env var) causes the live tests to actually execute
  (opt-in path proven, not just opt-out)
- [ ] `.github/workflows/ci.yml`'s test job invokes `scripts/test.sh`, not a hand-written
  glob/grep command
- [ ] `CLAUDE.md` documents `scripts/test.sh` as the canonical entrypoint
- [ ] No remaining occurrence of `grep -vE 'serve-github|provider-abi-conformance|cli-edit-parity-conformance'`
  anywhere in the repo (`git grep` returns empty)

## Definition of Done

- [ ] `scripts/test.sh` committed and run for real, output pasted showing the real pass count
- [ ] A real CI run (GitHub Actions, not local simulation) is green using the new script
- [ ] `adr/ADR-019-...md`'s `enforcement` field updated to point at `scripts/test.sh`

## Proposal

Move the taxonomy decision (which tests are safe-by-default vs opt-in-live) from external,
duplicated prose into the test files themselves, and consolidate the invocation command into one
script both docs and CI call — eliminating the class of drift ADR-019's Context section documents.
