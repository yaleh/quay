## Finding

The DIR-108 wiring audit (M172, 2026-07-26) found `plugin/test/plugin-packaging.test.mjs` sitting
on `master` with 2 failing tests, invisible to `ci.yml`'s test step because its glob
(`packages/*/test/*.test.mjs`) never matched `plugin/test/`. Nothing mechanical caught this — the
only source of truth for "which test files exist and should run" was a human remembering to keep
the CI glob current. ADR-019 decision item 4 requires a mechanical self-check generalizing this fix
so the same failure class cannot recur under a different, not-yet-invented path.

## Requested action

Write a check script (e.g. `scripts/test-coverage-check.ts`) that:
1. Globs the filesystem for every `**/test/*.test.mjs` file across the repo (packages/*/test/,
   plugin/test/, and any future test/ directory).
2. Compares that set against exactly what `scripts/test.sh` (DIR-109) actually invokes.
3. Exits non-zero, printing the specific orphaned file path(s), if any test file exists outside
   the canonical runner's reach.
4. Per ADR-018 (selfcheck fixture pattern): ships its own selfcheck fixture proving BOTH states —
   a deliberately orphaned test file makes it fail, removing it makes it pass.
5. Is wired as an early, cheap step in `.github/workflows/ci.yml` (fail-fast, before the full
   suite runs).

## Acceptance Criteria

- [ ] The check script exists and is runnable standalone (`node --experimental-strip-types
  scripts/test-coverage-check.ts`)
- [ ] Selfcheck fixture: planting an orphan test file in a scratch/fixture location makes the
  check fail non-zero with the orphan's path named in the output; removing it makes the check
  pass — both states demonstrated, not just the passing one
- [ ] `.github/workflows/ci.yml` runs this check as an early step, before the full test job
- [ ] Right now, with zero known orphans, the check passes cleanly against the real repo tree

## Definition of Done

- [ ] Script + its selfcheck fixture committed and green
- [ ] A real CI run shows the step executing and passing
- [ ] `adr/ADR-019-...md`'s `enforcement` field updated to include this script's invocation

## Proposal

A direct, generalized fix for the exact failure class the DIR-108 audit found: make "is every test
file reachable by the thing that's supposed to run it" a mechanically-checked invariant instead of
tacit knowledge.
