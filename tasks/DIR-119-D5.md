**type:** execution

## Proposal

Make `execute-milestone.js`'s Land phase literally invoke `composite-land.ts`'s
`buildLandTransaction()` as a pure transaction validator, and — because this is the last child in
DIR-119-D's ordered split, once all of DIR-119-D1 through D4 land — run the single, real, fresh,
end-to-end composite dispatch that exercises the FULL new pipeline (synthesis → phase-DAG Build →
per-shard Audit → typed-Gate → Reconcile → Land) together, then obtain the fresh independent wiring
audit DIR-119-D's own Requested action item 9 requires. Fifth and final child of DIR-119-D's split.
Depends on DIR-119-D1 through D4 all being landed.

### Problem framing (re-verified against current tree, 2026-07-29)

`composite-land.ts` has zero non-test importers anywhere in the tree — its `buildLandTransaction()`
and `legacySingletonLandShape()` exports are real, tested, and unused in production. The current
Land phase merges + bumps the counter directly with no independent transaction-shape validation.

## Chosen mechanism

Add a non-selftest `--land-json` mode to `composite-land.ts` invoking the existing, already-exported
`buildLandTransaction()`. Before any mutation it requires `ok:true`, `counterDelta===1`,
`dashboardEntryCount===1`, `taskCompletionCount===taskIds.length`, `landPolicy:"atomic"`, and exact
set-equal membership against Reconcile's output (DIR-119-D4); on any mismatch it produces
`needs-human` with zero counter/dashboard/status writes. Land rechecks and commits the one
already-decided transaction; it never re-derives verdicts. `legacySingletonLandShape()` (already
exported, currently unused in production) becomes the machine-asserted width-1 golden-replay oracle.

**End-to-end real proof.** Once DIR-119-D1 through D4 are all landed, dispatch one fresh, real
composite (2-3 real tasks is sufficient, width 7 need not be repeated) through the fully-wired
mechanism. From its real workflow RESULT record (`workflows/wf_*.json`'s `workflowProgress[]`,
which carries one `{type:"workflow_agent", label, phaseIndex}` entry per labeled dispatch — NOT
`journal.jsonl`, whose entries carry only `{type, key, agentId[, result]}` with no label or phase
id), confirm in one single run: manifest synthesis
(DIR-119-D1) → `build-plan`/`build-phase-<id>`×N/`build-integrate` (DIR-119-D2) →
`audit-shard-<id>`×M/`audit-combine` (DIR-119-D3) → typed Gate → `reconcile-apply` (DIR-119-D4) →
Land transaction, in that literal order, tree clean until `reconcile-apply`, atomic Land.

**Fresh independent wiring audit.** Explicitly briefed to (a) trace production import graphs for all
five composite-*.ts modules (build/audit/reconcile/land/manifest-synthesis) plus the new
manifest-synthesis step, and (b) exercise the Gate-failure branch — not only read journal call-counts
and AC-citation text, the exact checklist the prior DIR-119-C audit used and which missed these
defects. This closes the meta-gap DIR-119-D's own Finding names.

Once the audit confirms no refutation, re-verify DIR-119-C's own AC #5 (phase-DAG
Build/read-only shards/deterministic Reconcile "using the installed new workflow") and DIR-119's
parent AC #2/#3 — only then may DIR-119-C and DIR-119 be promoted (a separate re-adjudication step,
tracked outside this task).

### Key design decisions

- **Land is a transaction-commit validator only, never a second policy engine**, so there is exactly
  one place (Reconcile) that decides "did this land."

- **Legacy path is a hard boundary, not a fallthrough.** Width 1 stays completely untouched;
  `legacySingletonLandShape()` is the machine-asserted golden-replay comparison target, not a prose
  claim of equivalence.

### Risks and mitigations

- **Control-plane regression on the one script every future milestone runs through** — mitigated by
  keeping the repo-root halt sentinel present, never running this child concurrently with any other
  dispatch, running the full canonical test suite (not a subset) as part of this child's own
  Gate/DoD evidence.

- **This child is the integration point for four prior children's real wiring** — if any of
  DIR-119-D1 through D4 has a latent defect not caught by its own child-scoped audit, it surfaces
  here as an end-to-end failure. Mitigation: this child's own real dispatch is the first time all
  five mechanisms run together, and its own fresh independent audit is explicitly scoped to trace
  the FULL chain, not just this child's own Land-specific addition.

### Non-goals

No re-litigating DIR-119-D1 through D4's own already-audited scope — this child assumes their
independent audits already passed; if the end-to-end run surfaces a defect traceable to an earlier
child, file it as a new gap task against that child rather than silently patching it here. No
repeat of the width-7 canary — 2-3 real tasks is sufficient. No product-package or Provider ABI
changes.
