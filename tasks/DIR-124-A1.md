## Proposal

Define one canonical, minimal, append-only stage-event schema and instrument the 8 workflow
boundaries (Prepare admission in `prepare-milestone.js`; Verify/Prepared/Build/Audit/Gate/
Reconcile/Land in `execute-milestone.js` via its phase markers at lines 66/234/389/673/769/866/908)
to emit it — without changing dispatch order, concurrency, lifecycle results, or write authority.

First child of the DIR-124-A split (mechanism M1, `split-multi-mechanism` finding). No dependencies.

**Emission mechanism (the blocking finding from split review):** events are emitted by the workflow
JS itself, at wrapped `phase()`/dispatch helper boundaries, NOT by agents via structured output.
Each boundary appends one schema-validated event object to the per-run event log
(`experiments/quay-perpetual-stream/.workflow-events/<runId>.jsonl`, gitignored). A
`recordStageEvent({…})` helper is the single emission point; it validates against the schema module
below and is observational-only (no return-value coupling to stage dispatch).

## Chosen mechanism

M1 from the split-review inventory. `scripts/workflow-event-schema.mjs` (new) is the **first-class
home** of the canonical schema (the review finding `no-schema-home`: the schema must NOT be embedded
in an emission script). `recordStageEvent` lives in the same module; both `prepare-milestone.js` and
`execute-milestone.js` mirrors import it and call it at each boundary with the boundary name, the
run/candidate/task identity, stage/attempt, queued/start/end timestamps, agent-call label, execution
cwd/worktree, command/test identity, observed writes, base/candidate commit, outcome, and wait
reason/resource claim (RA1's full field set).

## Alternatives considered

- **Agent structured-output emission** — rejected: it couples content agents to the observability
  contract and cannot be guaranteed at every boundary.
- **Wrapping dispatch helpers only** — rejected: Prepare admission lives in the prepare workflow,
  which has no shared dispatch helper; an explicit per-boundary call is uniform.
- **Embedding the schema in an emission script** — rejected (review finding): DIR-124-B must extend
  the same schema; a first-class module is the single home.
