## Finding

Baseline metrics required by DIR-124 (stage wall/queue time, prompt bytes, agent-call count,
full-suite count, shared-writer count, observed write sets, Land wait/fence time, replay variance)
are today reconstructed from prose reports and Claude Code timelines, not measured mechanically.
Without a real before-state baseline, DIR-124-E's resource-aware scheduling has no comparison
surface.

## Requested action

1. Emit the RA5/RA9 metric set mechanically from the A1 event stream, covering the full
   Prepare-admission → Execute-Land range for available real samples.
2. Split mechanical-runner work from content-agent work; classify every metric.
3. Report stage wall/queue time, agent-minutes, tokens, finding novelty/recurrence, and
   artifact-class output where real evidence exists; missing fields are explicit unknowns.
4. Do not infer delivered value or change pass/fail policy — record the before-state only.
