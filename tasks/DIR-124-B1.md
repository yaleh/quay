## Proposal

Split from DIR-124-B (M236) — mechanism 1, the **canonical `RunIdentity` factory**. This child owns
`run-identity.ts` (both mirrors): the ONE identity-minting entry point for the milestone execution
substrate. Per the parent's DD2 + CLAIM-B1 (→ AC1/AC3), identity minting is a single factory called
once at dispatch; composite width changes `taskIds` cardinality, never the envelope type. `runId`
is derived from the harness `$CLAUDE_CODE_SESSION_ID` echo + a per-dispatch nonce — never a
caller-asserted string (the "cannot be forged" property is mechanical, a wiring fact not prose).

### Chosen mechanism

A new TypeScript CLI module `experiments/quay-perpetual-stream/scripts/run-identity.ts` (byte-identical
mirror at `plugin/scripts/run-identity.ts`), zero-dependency, importing only `node:fs`/`node:path`/
`node:crypto`/`node:child_process`:

1. **Typed `RunIdentity` fields:** `runId` (`$CLAUDE_CODE_SESSION_ID` + per-dispatch nonce),
   `candidateId`, `taskIds`, `attempt`, `baseCommit`, `candidateCommit` (bound when the Build
   candidate-generation commit exists; re-checked at Audit/Gate/Land), `workflowSourcePath`,
   `workflowSourceHash`, `workflowSourceCommit`, `runtimeGeneration`, `taskHash`, `charterHash`,
   `planHash`, `materialInputHashes`.
2. **One factory, two shapes:** the SAME factory produces a singleton width-1 shape and a composite
   shape — identical envelope type (AC1). Composite changes only `taskIds` cardinality.
3. **CLI surface:** `--create <json>` is the workflow callsite (dispatched via the established
   `node --experimental-strip-types <abs path>/run-identity.ts --create '<json>'` pattern through
   `agent()`); embedded `--selftest` validates the factory round-trips and the session-id derivation.
4. **Mirror parity:** both mirrors byte-identical (G3); `diff` exit 0 at Land.

**WIRING-CLAIM (B1-IDENTITY-MINT):** `execute-milestone.js` (both mirrors) invokes
`run-identity.ts --create` at Verify entry and owns identity minting; `runId` is derived from the
harness `$CLAUDE_CODE_SESSION_ID` echo (a wiring fact, not prose). → AC1, AC3.

**WIRING-CLAIM (B1-CANDIDATE-BIND):** `candidateCommit` is bound at Build-integrate (the SOLE
commit-creator) and re-checked at Audit/Gate/Land so a moved candidate commit fails closed.
