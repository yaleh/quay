## Proposal

Split from DIR-124-B (M236) — mechanism 4, the **additive workflow wiring** in both
`execute-milestone.js` mirrors. This child owns the `execute-milestone.js` callsites that mint
identity, append stage events, write green-boundary receipts, replace the Verify cache lookup, and
dispatch the resume plan. Per the parent's mechanism 5 + CLAIM-B1/B2/B4/B5 (→ AC1, AC3, AC4, AC5, AC7).

### Chosen mechanism

Additive wiring in both mirrors (`.claude/workflows/execute-milestone.js` and
`plugin/workflows/execute-milestone.js`, byte-identical):

1. **Mint `_runIdentity` at `phase('Verify')` entry** via `run-identity.ts --create` (DIR-124-B1's
   script; CLAIM-B1).
2. **Per-boundary append + green-boundary receipt at all seven phases** — Verify (L66), Prepared
   (L234), Build (L389), Audit (L673), Gate (L769), Reconcile (L866), Land (L908): append a `StageEvent`
   via `workflow-journal.ts --append-stage` and, on green, write a hash-bound `StageReceiptEnvelope`
   via `stage-receipt.ts` (CLAIM-B2/B3).
3. **Replace the Verify cache LOOKUP (L121-128)** with a `workflow-journal.ts --load-validated-verify-cache`
   callsite and CLOSE the loop by persisting `verifyCacheUpdates` through `--persist-verify-cache`
   (CLAIM-B4) — the caller no longer owns the loop.
4. **On dispatch with a journal present**, run `workflow-resume.ts --resume-plan` and start at the
   earliest invalid stage (CLAIM-B5).
5. **Expose the migration adapters** as reachable one-way callsites: `--migrate-dir124a`,
   `--migrate-dir126d`, `--migrate-prepare-ledger` (CLAIM-B6/B7).
6. All new production callsites are bash `node --experimental-strip-types <abs path>/<script>.ts <mode>`
   invocations via `agent()` — no new DSL import mechanism (DD9).

**Compatibility:** behavior-preserving on the legacy dispatch path — every new callsite is additive
(mints identity, appends journal, persists cache, computes resume plan); the legacy Verify cache
surface and phase order are untouched. The four existing golden-replay
`plugin/test/execute-milestone-*.test.mjs` files stay green UNMODIFIED (G2), and the mirror `diff`
must stay clean (G3).

**WIRING-CLAIM (B4-WIRING):** both `execute-milestone.js` mirrors invoke `run-identity.ts --create`
at Verify entry, append `StageEvent`s + green-boundary receipts at all seven phase boundaries, replace
the Verify cache LOOKUP with `--load-validated-verify-cache`, persist `verifyCacheUpdates` via
`--persist-verify-cache`, and dispatch `--resume-plan` on journal-present dispatch — all additive, all
via the established agent-dispatch pattern. → AC1/AC3/AC4/AC5/AC7.
