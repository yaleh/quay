**type:** execution

## Proposal

Implement the convergence sequence in
`docs/proposals/quay-milestone-workflow-git-crystallization.md` after [[DIR-117]] and [[DIR-119]]
complete, but before [[DIR-118]]. Turn the live milestone workflow from a prompt-coupled monolith
into a small executable control-plane kernel with one physical isolation service, hash-bound stage
receipts, narrow adapters, versioned execution policy, and resource-aware stage scheduling.

Split the work into ordered children:

1. [[DIR-124-A]] records stage observability, intentional invariants, and golden replay baselines.
2. Existing [[DIR-123]] restores real worktree isolation; the existing
   `gap-build-phase-iteration-evidence-path-not-single-sourced` then removes the remaining evidence
   root ambiguity.
3. [[DIR-124-B]] establishes canonical execution identity, journal, receipts, cache, and resume.
4. [[DIR-124-C]] extracts the deterministic kernel and Stage Adapter ABI.
5. [[DIR-124-D]] moves routing/gate/test/resource policy into a registry and deletes duplicate
   prompt/driver representations.
6. [[DIR-124-E]] uses the resulting boundaries for resource-aware cross-stage pipelining.
7. **[[DIR-124-F]] (registered 2026-08-01, human decision)** is the runtime-contract
   GroundTruthRegistry child (ADR-020) — a "fix the pipeline every future prepare runs
   through" priority that executes BEFORE the B/C/D/E chain. **ID-resolution:** the id
   `DIR-124-F` was previously reserved in Requested action item 6 for a potential future
   rolling effect-lease child; the human decision reassigned it to the GroundTruthRegistry
   child. The effect-lease decision, if justified at DIR-124-E close-out, must use a distinct
   id.

Do not duplicate work already owned by [[DIR-119-D]]: phase-DAG Build, literal read-only Audit
shards, deterministic Reconcile, and composite wiring are prerequisites this directive consumes.
Do not pull [[DIR-118]]'s post-Land, later-runtime-generation Wiring Audit or `done`-promotion
contract into this directive. DIR-124 supplies the stable substrate on which that policy can later
be implemented without another control-plane rewrite.

## Plan

N/A — parent directive resolved only through its ordered children and external prerequisites.
Parent completion is exactly the completion of DIR-124-A through DIR-124-E plus the explicitly
named worktree/path prerequisites; the parent is not independently SELECTable. **DIR-124-F**
(the GroundTruthRegistry child) is a registered child whose completion is tracked
independently of the A–E ordered sequence — it executes BEFORE B/C/D/E per the 2026-08-01
human decision and does not gate A–E's declared order.

## Finding

The live `.claude/workflows/execute-milestone.js` is approximately 490 lines / 38 KB and owns
argument compatibility, task policy, Verify caching, preparation gating, Build method, Audit
judgment and writes, Gate dispatch, Git/worktree semantics, lifecycle mutation, dashboard/backlog
updates, and serial/concurrent Land variants. Small changes have repeatedly deformed unrelated
behavior: cache refactoring removed Build timeout discipline, Audit visibility pressure caused
worktree isolation to be removed, and checked composite modules remained outside the live
production call graph.

The repository now has useful crystal nuclei—DIR-119's composite contracts/Reconcile,
DIR-117's preparation receipt, DIR-123's intended physical isolation, and the stage-pipelining
proposal—but no common kernel joining them. Implementing DIR-118 immediately would mix this
unfinished substrate with a new post-Land lifecycle policy and force both concerns through the
same high-curvature workflow surface.

## Acceptance Criteria

- [ ] DIR-124-A through DIR-124-E are all `done`, real-landed, and independently audited in their
  declared order.
- [ ] DIR-123 is done and all top-level/intra-composite worktree use routes through one reusable
  physical-isolation implementation.
- [ ] `gap-touches-orthogonality-symlink-isdirect-mismatch` and
  `gap-build-phase-iteration-evidence-path-not-single-sourced` are resolved before the dependent
  worktree/receipt stages claim completion.
- [ ] The live workflow consumes DIR-119-D's phase-DAG Build, read-only Audit shards, and
  deterministic Reconcile rather than maintaining a second prompt-only description.
- [ ] A stage can be retried or resumed from validated receipts without reinterpreting caller
  folklore; stale input/base/workflow/runtime-generation receipts fail closed.
- [ ] Only deterministic Reconcile/fenced Land has authority to mutate shared task lifecycle,
  ABSORB, dashboard, backlog, counter, or integration-branch state.
- [ ] Task routing, required gates, test profiles, and resource claims have one executable policy
  owner; superseded workflow/OUTER-LOOP copies are deleted or reduced to generated pointers.
- [ ] Real stage-pipeline evidence shows useful cross-milestone overlap without unbounded full-suite,
  port, CPU, memory, agent, or integration-writer contention.
- [ ] DIR-124-E records an evidence-backed explicit decision to create or reject a later rolling
  Ready-to-Land/effect-lease child; absence of a decision fails this parent.
- [ ] DIR-118's unique post-Land Wiring Audit and lifecycle-promotion semantics remain deferred and
  are not silently implemented or weakened by this directive.

## Definition of Done

Standard `experiments/quay-perpetual-stream/inherited-core.md` DoD clauses apply. Per DIR-026,
the parent cannot be marked done merely because modules, schemas, prompts, or fixtures exist.

- [ ] Every child and prerequisite named in Acceptance Criteria has real execution evidence, not
  same-generation assertion.
- [ ] Legacy singleton and real composite paths both cross the installed new kernel successfully.
- [ ] Negative controls cover wrong worktree, hostile Audit mutation, stale/tampered receipt,
  invalid transition, resource exhaustion, and integration-writer contention.
- [ ] The final independent wiring audit traces production call graphs, write authority, receipt
  validation, and real stage overlap rather than accepting prompt claims.
- [ ] Parent/child lifecycle gates pass only after DIR-124-A through DIR-124-E are done.
