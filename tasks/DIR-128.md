## Proposal

**人的裁定（2026-08-11 14:3xZ + 14:4xZ 补充，逐字意图）**：在 B/C 上进行开发时，都应使用 `claude-deepseek` + `deepseek-v4-flash`，命令行应与本机当前 outer/inner 的命令行一致。

**14:4xZ 补充（含此前遗漏的关键部分，使本任务完整可执行）**：

**① `claude-deepseek` 实为本机 `~/.local/bin/claude-deepseek` 的 wrapper 脚本**，逻辑 = `source ~/.local/etc/deepseek-api-key`（读 DEEPSEEK_API_KEY）→ `export ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"` → `export ANTHROPIC_AUTH_TOKEN="$DEEPSEEK_API_KEY"` → `exec claude "$@"`——**真正让「用 deepseek」生效的是这两个 env var，不是 claude-deepseek 这个名字本身**。

**② launch.settings.json 顶层 env 块（outer/inner 角色无覆盖，直接继承）**：
```
CLAUDE_CODE_MAX_CONTEXT_TOKENS=917000
CLAUDE_CODE_AUTO_COMPACT_WINDOW=917000
CLAUDE_AUTOCOMPACT_PCT_OVERRIDE=80
CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1
CLAUDE_CODE_DISABLE_MOUSE=1
CLAUDE_CODE_ENABLE_PROMPT_SUGGESTION=false
```

**③ CLI（--dry-run 实测）**：
```
claude-deepseek --settings <repo>/.claude/launch.settings.json --exclude-dynamic-system-prompt-sections --prompt-suggestions false --model deepseek-v4-flash -n quay-outer/inner
```

**人已确认（14:4x）**：B/C 上已有 DeepSeek 密钥文件 `~/.local/etc/deepseek-api-key`，**无需分发**——密钥文件本身不是本次要处理的缺口。
