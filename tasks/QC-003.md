- Core MCP leg: `action_list` tool → same advance button
- Web UI leg: `GET /task/SYM-1` → Advance button label + form target

are covered by the script with all three legs (CLI, Core MCP, Web UI).

  has no write form or gate-check page. These are correctly absent per DIR-010.
- MCP resources (`provider://manifest`) — manifest access is a meta-capability,
  not in §9's listed data operations. Correctly not tested.

**Gap finding**: NONE. The enumeration found no uncovered surface in the
§9-defined shared capability set.
