## Proposal

The quay-core-bootstrap experiment has accumulated two significant operational
findings that are not yet reflected in any project-level changelog:

1. **Manda port-discovery finding** (iteration 4): The daemon address is stored
   in `.manda/hub.addr` — not at the previously-assumed port 28912. Iterations
   0-3 all probed the wrong port and concluded the daemon was unreachable. The
   correct precondition check reads `.manda/hub.addr` directly. This finding
   is currently documented only in `.manda/NOTES.md` (QC-005) and iteration
   reports — not in any project-wide, human-facing changelog.

2. **Three confirmed manda reliability tiers** (iterations 4-6): The
   `mcp__plugin_manda_manda__Agent` conditional primitive has been probed at
   three complexity levels:
   - Trivial (PONG echo): SUCCESS (1/1, iteration 4)
   - Medium (single-file read + structured JSON): SUCCESS (1/1, iteration 5)
   - Complex (multi-file read + adversarial analysis + structured verdict):
     SUCCESS (1/1, iteration 6 — 150s timeout confirmed)
   This three-tier reliability envelope is a significant operational fact. No
   prior iteration's changelog or top-level document captures all three.

findings. This task creates it with a single entry covering both findings.
