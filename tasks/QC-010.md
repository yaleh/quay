## Proposal

The experiment README (`experiments/quay-core-bootstrap/README.md`) currently has no
iteration history summary. The full history exists across 10 separate `iterations/
iteration-N.md` files, but a reader cannot see the progression (which objectives were
advanced, what the V scores were at each step, when σ_QC milestones occurred) without
reading all 10 files.

The gap: no consolidated iteration-history table exists in the README. The iteration-9.md
§9 Practical Convergence Assessment references prior iterations but has no tabular summary
of the experiment's arc.

Approach: add a `## 10. Iteration history` section to README.md containing a compact
table: iteration number, date, primary work, V_instance, V_meta, σ_QC, and convergence
status. This is a pure documentation addition — no source files in any package are
touched.

## Plan

**Phase 1** — draft the iteration history table with one row per iteration (0-9):

  §10 (convergence status). Data already confirmed in provenance.md for QC-* tasks.
