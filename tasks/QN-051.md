## Proposal

`packages/quay-native/provider.yml` (the native Provider's own static
self-declaration, cited by `quay-native-design.md`, both Skill SKILL.md
files, and the proposal itself) carries three v0/seed-era comments that
have been stale since very early in this experiment's history and were
never corrected:

1. **Line 16** — `data.write: true    # task_write via `quay-native task
   edit` (v0: raw CLI op; MCP task_write not yet wired)`. This is false:
   `task_write` has been a fully registered MCP tool (with CAS support)
   in `packages/quay-native/src/mcp-server.js` since the very first
   commit (`5b452aa`, the v0 walking skeleton itself) — it was never
   "not yet wired." It is exercised end-to-end and byte-compared against
   the CLI in `packages/quay-native/test/abi-symmetry.mjs` (`task_write`,
   `task_write_value_equivalence`, and the `extra`-isolation case).

2. **Line 18** — `skill: true        # quay:* Skills declared below (v0:
   seed-driven, see note)`. This is false: `quay:author` and
   `quay:execute` are real, native Skills (`packages/quay-native/
   skills/author/SKILL.md`, `.../execute/SKILL.md`) that have been
   driving the majority of this experiment's own `done` tasks since the
   seed's retirement (documented across `experiments/quay-native-bootstrap/provenance.md`); they
   are not "seed-driven" — the seed (epicd) was retired iterations ago.

3. **Lines 36-41** — the `status_skill_map` comment block: "NOTE
   (v0/iteration 0, honest): `quay:author` / `quay:execute` do not
   exist as native Skills yet (σ=0). This table is the target mapping; at
   v0 the action button's payload is composed from this table but routes
   to the SEED (epicd `authoring-convergence` / `fixpoint-convergence`),
   not to `quay:author`/`quay:execute`." This entire note describes the
   σ=0 iteration-0 state and has been false since the Skills' own
   retirement of the seed; it misleads a reader of the single
   most-frequently-cited Provider manifest in the repo into thinking the
   Skills still do not exist.

This is the same class of documentation-accuracy defect closed by QN-049
(`packages/quay-github/provider.yml`/`DESIGN.md`, iteration 38) and
QN-050 (`quay-native-design.md` §8, iteration 39) — a stale comment in a
config/design file, uncorrected across many iterations, discovered by a
fresh, exhaustive re-read and direct cross-check against live code/Skill
state rather than assumed current.
