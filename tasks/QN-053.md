## Proposal

All three top-level proposal documents —
`docs/proposal/quay-proposal.md`, `docs/proposal/quay-native-design.md`,
and `docs/proposal/quay-bootstrap-experiment.md` — still carry a
`**Status:** Draft (pre-implementation)` header line, unchanged since
each document's original authoring. This has been stale since well
before iteration 41 first flagged it as a candidate fix (iteration 41's
own problem list item 5): the repository now has 99 commits, 41 completed
BAIME iterations, 51 allocated native task IDs (`QN-001`..`QN-052` minus
`QN-018`), a working v0-through-stage-2+ skeleton (native Provider +
GitHub Provider both built and running, per iteration 25's QN-035 and
iteration 18's QN-029), and 24 passing regression-test files across all
three packages. "Draft (pre-implementation)" misleads a fresh reader of
any of these three documents into thinking no implementation has
started, when in fact implementation has been substantial and ongoing
for the entire life of this experiment.

This is the same class of documentation-staleness defect closed by
QN-049 (iteration 38, `quay-github/provider.yml`/`DESIGN.md`), QN-050
(iteration 39, `quay-native-design.md` §8), and QN-051 (iteration 40,
`quay-native/provider.yml`'s stale v0/seed-era comments) — a stale status
line in a design/proposal document, uncorrected across many iterations,
discovered by a direct fresh re-check (`grep -n "Status:\*\*" docs/proposal/*.md`)
rather than assumed current.

**Distinguishing this from QN-050 (which also touched
`quay-native-design.md`):** QN-050 corrected §8's specific "open
decisions" list content. This task corrects a different, higher-level
element of the same and two sibling documents — the document-level
`**Status:**` metadata line itself — and additionally touches
`quay-proposal.md` and `quay-bootstrap-experiment.md`, neither of which
QN-049/QN-050/QN-051 modified.

**Genuine, unplanned discovery made during this task's own execution
(honest mid-authoring correction, not silently smoothed over):**
`docs/proposal/quay-bootstrap-experiment.md` — the experiment's own
authoritative protocol document — is listed in `.gitignore` (line 1,
present since the very first `.gitignore` commit, `af577cd`) and is
therefore **not tracked by git at all**, unlike its two sibling documents.
`git status --short docs/proposal/` confirms it does not even appear as
untracked (`??`) the way a normal untracked file would; `git check-ignore
-v` confirms the exclusion is deliberate and explicit. This means this
task's edit to that file's Status line is a real, on-disk content fix,
but is **structurally invisible to `git diff`/`git commit`** — it cannot
be committed via a normal `git add` without first changing `.gitignore`,
which is outside this task's scope (a `.gitignore` change was not
requested or authorized, and unilaterally making this file trackable
would be an unrequested scope expansion beyond a Status-line fix). AC3/
AC4 below are revised in light of this discovery to describe the actual,
honest outcome rather than the originally-planned one.

## Plan

1. Re-confirm via `grep -n "Status:\*\*" docs/proposal/*.md` (done above)
   that exactly three files carry the stale `Draft (pre-implementation)`
   line, and that `glossary.md` carries no such line (it has no Status
   metadata field at all, confirmed by inspection).
2. Edit each of the three files' `**Status:**` line in place, replacing
   `Draft (pre-implementation)` with an accurate, evidence-based
   description of the current state (referencing the number of completed
   iterations and the existence of both Providers) — while preserving the
   rest of each document's metadata block (Date/Owner/Relates/etc.)
   unchanged.
3. Do not alter any other content in any of the three files — this is a
   metadata-line-only fix, zero prose/protocol/design content change.
4. Discover (as happened) that `quay-bootstrap-experiment.md` is
   gitignored; do not attempt to change `.gitignore` to force-track it
   (out of this task's scope); make the on-disk edit anyway (still an
   honest, real improvement for any reader who opens the file directly)
   and report the discovery plainly in this task and the iteration report
   for human attention.
5. Re-run the full regression suite (24 `*.test.mjs` files across all
   three packages, plus `abi-symmetry.mjs`) and confirm zero `.js` diff,
   zero regressions.
6. Confirm `git diff --stat` touches only the two git-tracked named
   `.md` files (`quay-proposal.md`, `quay-native-design.md`) — not three,
   since `quay-bootstrap-experiment.md` is gitignored and invisible to
   `git diff` regardless of its on-disk content.
