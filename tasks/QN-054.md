## Proposal

`experiment/README.md`'s own `**Status:**` line still reads `Not started
(pre-iteration-0)`, unchanged since the file's original authoring at
iteration 0. This has been stale since iteration 0 itself completed: the
repository now has 100+ commits, 42 completed BAIME iterations, 52
allocated native task IDs (`QN-001`..`QN-053` minus `QN-018`), a working
v0-through-stage-2+ skeleton (native Provider + GitHub Provider both
built and running), and 24 passing regression-test files. "Not started
(pre-iteration-0)" actively misleads a fresh reader of this file — the
experiment's own top-level operational README — into thinking no
iteration has yet run, the opposite of the truth.

This is the same class of documentation-staleness defect as QN-049
(iteration 38), QN-050 (iteration 39), QN-051 (iteration 40), and QN-053
(iteration 42, three top-level proposal docs' own Status lines) — a
stale status line, uncorrected across many iterations, discovered by a
direct fresh re-check of this file (read in full this iteration as part
of the mandatory fresh-read-every-file protocol discipline) rather than
assumed current. Distinct from QN-053: that task touched the three
`docs/proposal/*.md` files; this task touches `experiment/README.md`
itself, which QN-053 never modified and which was not re-checked by
iteration 42 (whose search scope was limited to the three proposal
documents already flagged by iteration 41's own problem list).

## Plan

1. Re-confirm via `grep -n "^\- \*\*Status" experiment/README.md` that
   the stale line exists exactly once, at line 3.
2. Edit the `**Status:**` line in place, replacing "Not started
   (pre-iteration-0)" with an accurate, evidence-based description of the
   current state (iteration count, task-ID count, Provider status),
   while preserving every other line of the metadata block and all body
   content unchanged.
3. Do not alter any other content in the file — this is a metadata-line-
   only fix, zero content change beyond the Status line itself.
4. Re-run the full regression suite (24 `*.test.mjs` files across all
   three packages, plus `abi-symmetry.mjs`) and confirm zero `.js` diff,
   zero regressions (expected, since this touches only a `.md` file).
5. Confirm `git diff --stat` touches exactly one file
   (`experiment/README.md`), one line changed.
