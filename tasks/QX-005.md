## Proposal

Improve the `quay` CLI help output in `packages/quay/bin/quay.js` to address UQ-001 (one-line --help) and UQ-002 (broken subcommand help). Currently, `quay --help` does nothing (falls through to the generic usage error), and `quay task --help` or `quay task list --help` either errors or shows nothing useful.

The fix is to detect `--help` / `-h` flags in the argument parsing and print structured usage documentation before exiting 0. No external dependency is needed — help text is rendered as a simple string.

## Plan

Phase 1: Add top-level `--help` detection in `main()`.
- If `cmd === "--help"` or `cmd === "-h"` or `flags.help` is true with no meaningful command, print a full usage guide and exit 0.

Phase 2: Add subcommand-level `--help` detection.
- If `sub === "--help"` or `sub === "-h"` or `flags.help` is set in any branch's context, print subcommand-specific usage.

Phase 3: Add test to `packages/quay/test/cli.test.mjs`.
- Assert `quay --help` exits 0 and output includes "Usage:" and lists main subcommands
- Assert `quay -h` exits 0 (alias)
- Assert help text mentions `--prefix` (cross-linking QX-002)

## AC
- [x] `quay --help` exits 0 and prints a structured usage guide including subcommands and examples

- [x] `quay task list --help` exits 0 and prints task-list-specific flag documentation
- [x] A new test in `packages/quay/test/cli.test.mjs` asserts `--help` content
