## Proposal
`quay task list --prefix` (flag provided with no argument value) crashes with `TypeError: prefix.toUpperCase is not a function`. When `--prefix` is passed without a value, `parseFlags()` sets `flags.prefix = true` (boolean), and the filter expression `prefix.toUpperCase()` throws because `true` is not a string. This is a regression introduced by QX-002 (iteration 1).

Found by: simulated-user comparison reviewer (iteration 1); filed as SH-001 in gap-list.md.

## Plan
1. In `packages/quay/bin/quay.js`, after `const prefix = flags.prefix;`, add a guard:
   - If `prefix` is not a string (e.g. boolean `true`), print `Error: --prefix requires a value (e.g., --prefix QX)` to stderr and exit with code 1.
2. Add test 15 in `packages/quay/test/cli.test.mjs`:
   - Assert `quay task list --prefix` (no value) exits 1 with the usage error on stderr.
   - Assert existing prefix-with-value tests are not broken (regression guard).
