## Proposal

CLI `--sort updated` is silently ignored (CB-012) and sort-by-time is absent from both CLI and Web UI (CB-004, CB-005). The cross-experiment maintainer and comparison-reviewer personas both flagged this as a significant gap: there is no way to find the most recently modified task from any surface. File mtime is the available timestamp signal (task front-matter has no `created`/`updated` field).

## Plan

Decision: extend `quay-native`'s `taskList()` to include `updatedAt` (fs.statSync mtime on each task file). This flows through the MCP interface naturally (already included in the JSON) and lets both CLI and Web UI sort without duplicate fs.stat calls.

Phase 1: Add `updatedAt` to quay-native's task object (store.js `list()` method).
Phase 2: Wire `--sort updated` in `bin/quay.js` to sort by `updatedAt` descending.
Phase 3: Add `?sort=updated` support in `serve.js`, with "Updated ↓" nav link.
Phase 4: Add tests (CLI sort-by-updated; Web UI sort-by-updated).
