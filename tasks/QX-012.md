## Proposal
At 375px viewport (mobile), the list-page table has 6 columns (id, status, role, title, labels, actions). The `role` and `labels` columns consume enough width that the `actions` column (containing the Advance button) is hidden off-screen to the right. The mobile-single-task simulated-user persona found this in iteration 2 (UQ-011 and UQ-012).

The fix is a CSS `@media (max-width: 600px)` rule hiding `role` and `labels` columns.

## Plan
Phase 1: Add class names `col-role` and `col-labels` to th/td elements for role and labels columns.
Phase 2: Add responsive CSS rule in pageStyles() hiding .col-role and .col-labels at ≤600px.
Phase 3: Add serve.test.mjs assertions.
