## Proposal
When a user clicks Advance and the gate conditions are not met, the action POST handler in serve.js silently redirects with no error message. The mobile-single-task and new-contributor simulated-user personas found this in iteration 2 (UQ-013).

The fix: check gate condition before delivering trigger; redirect with ?error= on gate-fail; render error/success banners on list and detail pages.

## Plan
Phase 1: Gate check before deliverTrigger in action POST handler.
Phase 2: Error banner in list page and detail page for ?error= param.
Phase 3: Success banner for ?success= param on gate pass.
Phase 4: addParam() helper to append params to redirect URLs.
Phase 5: Tests.
