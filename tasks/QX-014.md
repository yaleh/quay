## Proposal
The Advance button has no tooltip, hover text, or post-action confirmation. The new-contributor simulated-user persona found this in iteration 2 (UQ-014).

The fix: add `title="Advance task to next status"` to list-page buttons; add target-status title (`"Advance to ready"`, `"Advance to done"`) to detail-page buttons based on current task status.

## Plan
Phase 1: Add title= to list-page action button render.
Phase 2: Add target-status title= to detail-page button render using nextStatusMap.
Phase 3: Add serve.test.mjs assertions.
