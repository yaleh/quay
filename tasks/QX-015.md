## Proposal
The Web UI homepage shows a table of 100+ tasks with no explanation of what Quay is or how to get started. The new-contributor simulated-user persona confirmed this as a significant barrier in iteration 2 (UQ-003, escalated from minor to significant).

The fix: add an orientation banner div to the list-page HTML with a brief project description, styled subtly via .orientation-banner CSS class.

## Plan
Phase 1: Add orientation banner HTML before the h1 on the list page.
Phase 2: Add .orientation-banner CSS in pageStyles().
Phase 3: Add serve.test.mjs assertion.
