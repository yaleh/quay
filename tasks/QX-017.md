## Proposal
Fix UQ-011 (remainder): the actions column on the Web UI list page still overflows at 375px viewport for long task IDs and unfiltered pages. The iteration-3 fix (hiding col-role and col-labels) works for short-ID filtered pages but fails on the unfiltered page where the actions column right edge reaches ~436px vs 375px viewport. The solution is sticky positioning: `position: sticky; right: 0` on the actions column th and td cells makes the Advance button always visible even when the table scrolls horizontally.

## Plan
Phase 1: Update serve.js pageStyles():
- Add `position: sticky; right: 0; background: var(--bg-table, #fff); z-index: 2;` to the @media (max-width: 600px) block for the actions column header (th:last-child or .col-actions class).
- Add the same sticky rule to td in the actions column at mobile viewport.
- Add .col-actions CSS class to the th and td elements in the actions column.
Phase 2: Tests:
- serve.test.mjs: test that the CSS output includes position:sticky and right:0 for the actions column at mobile.
