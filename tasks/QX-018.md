## Proposal
Fix UQ-017: the updatedAt timestamp is tracked internally and used for sort ordering but never displayed anywhere. Users cannot see task recency without inferring from sort position. Add a relative-time display ("2h ago", "3d ago") in both the list page (new "Updated" column) and the detail page ("Last updated: X ago"), using a simple relativeTime() helper function. The data is already available in task.updatedAt (ms timestamp from quay-native's store.js).

## Plan
Phase 1: Add relativeTime() helper to serve.js:
- `function relativeTime(ts)` — given a millisecond timestamp, return "Xm ago" / "Xh ago" / "Xd ago" / "Xs ago" based on elapsed time. Use Date.now() for the reference point.
Phase 2: Add "Updated" column to list page table:
- Add `<th>updated</th>` column header to the list table (after labels, before actions).
- Each task row: add `<td class="col-updated">${escapeHtml(relativeTime(t.updatedAt))}</td>` or "—" if updatedAt is absent.
- Hide col-updated at mobile (@media max-width: 600px) — same pattern as col-role/col-labels.
Phase 3: Add "Last updated" field to detail page:
- After the meta line (role/labels/parent), add `<p class="meta">last updated: ${escapeHtml(relativeTime(t.updatedAt))}</p>` if updatedAt is defined.
Phase 4: Tests:
- serve.test.mjs: test that list page includes "updated" column header and a time element.
- serve.test.mjs: test that detail page includes "last updated" text.
