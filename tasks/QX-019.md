## Proposal
Fix UQ-018: the list-page Advance button shows a generic "Advance task to next status" tooltip, while the detail-page already shows the specific target status "Advance to ready". This inconsistency was noted by both the new-contributor and comparison-reviewer simulated-user personas in iteration 3. The detail page already has nextStatusMap = { todo: "ready", ready: "done" }; the list page needs the same per-task computation.

## Plan
Phase 1: Update list-page Advance button tooltip in serve.js:
- In the list route's row renderer, add a nextStatusMap lookup per task: const nextStatusMap = { todo: "ready", ready: "done" }; const nextStatus = nextStatusMap[t.status];
- Change button title attribute from generic "Advance task to next status" to `title="Advance to ${nextStatus}"` when nextStatus is known, falling back to the generic text when not.
Phase 2: Tests:
- serve.test.mjs: test that list-page Advance button for a todo-status task has title="Advance to ready" (not just the generic text).
