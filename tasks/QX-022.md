## Proposal
UQ-004 (minor) has been open since iteration 0. CLI `task list` (non-JSON) shows `id\tstatus\trole\ttitle` with no timestamp. Since QX-018 (iteration 4), `updatedAt` is included in every task's data from the provider. The Web UI already displays relative time via `relativeTime()`. The CLI should mirror this with a rightmost "updated" column in the plain-text table output, using the same relative-time logic. This closes UQ-004 without any new API calls or provider changes.

## Plan
Phase 1 — Add `relativeTimeCli()` to CLI in `bin/quay.js` (self-contained copy, not imported from serve.js which starts an HTTP server at module load time).
Phase 2 — Add "updated" column to non-JSON output as rightmost tab-separated field.
Phase 3 — Tests: CLI test 19 in `cli.test.mjs` verifies 5-field output and "ago" timestamp.
