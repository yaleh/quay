## Proposal

When there are 40+ distinct labels, the label nav becomes a flat wall. Add a threshold (25 visible labels) beyond which a "… N more labels" note appears. Show at most 25 labels in the nav; if `allLabels.length > 25`, append a non-link note: `… ${allLabels.length - 25} more labels`. This is a reasonable design decision for a small project tracker.

## Plan

1. `packages/quay/src/serve.js`: After building `allLabels` array (sorted), take first 25. If `allLabels.length > 25`, append a non-link note at the end of the label nav entries before `.join(" · ")`.
2. `packages/quay/test/serve.test.mjs`: Add a test that with 30 distinct labels, the nav HTML contains "more labels".

## AC

- [x] When truncated, a "… N more labels" note appears (non-clickable)
- [x] When 25 or fewer labels exist, no truncation occurs (no regression)
