## Proposal

Bundle three minor gaps into a single implementation pass:

1. **UQ-024**: `--search <query>` returns 0 results when user searches for a label name with no hint to try `--label`. Add a zero-result hint to CLI output: "Hint: use --label to filter by label, or --search to match title/body content."
2. **UQ-026**: Web UI "clear" (`?q=`) link resets ALL filters instead of just clearing the query. Fix: make the clear link preserve status/label/sort/prefix params and only remove `q`. Use `buildHref(statusFilter, sortKey, labelFilters, null, prefixFilter, null)` rather than a bare `/`.
3. **UQ-023 / store.js statSync**: The redundant `statSync` in `list()` after QX-018 — `get()` already fetches mtime and sets `updatedAt`; `list()`'s subsequent post-`get()` stat call is redundant. Remove the redundant stat in `list()` and rely on the value `get()` already set.
