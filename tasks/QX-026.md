## Proposal

Sort the label navigation by usage frequency (most-used labels first) and ensure active filter labels always appear in the visible nav regardless of alphabetic position. Closes UQ-028 (alphabetic ordering hides most-used labels) and UQ-027 (active label hidden by truncation).

## Plan

1. Count label frequency across all tasks (Map: label → count)
2. Sort allLabels by count descending, then alphabetically within equal counts
3. After computing visibleLabels = sorted.slice(0, 25), check if any active labelFilters are absent
4. If so, pin those active labels to the front and adjust hiddenLabelCount to keep display total = 25
5. Add serve.test.mjs tests: frequency sort works, active-label pin works, hidden count accurate
