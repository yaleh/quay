## Proposal

Exclude structural markdown heading lines (lines starting with one or more # followed by a space) from the body search index. This prevents "Proposal", "Plan", "AC", "DoD" etc. from matching 117/118 tasks just because every task body has those section headers. Closes CB-017.

## Plan

1. Add stripHeadings(text) function to both bin/quay.js and serve.js:
   ```
   function stripHeadings(text) {
     return (text || '').split('\n').filter(line => !/^#+\s/.test(line)).join(' ');
   }
   ```
2. Change search filter in bin/quay.js and serve.js to use stripHeadings(t.body) instead of (t.body || "")
3. Add tests: body with ONLY heading lines — "Proposal" search should NOT match; body with actual prose — should match
