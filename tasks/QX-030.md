## Proposal
MCP `task_list` returns ALL tasks in one response. With 100+ tasks in a real workspace, this produces large responses (measured at 550K chars for 94 tasks at iteration 0) that exceed inline processing limits. Add pagination so AI agents can request a manageable subset. Closes CB-010 and UQ-008.

## Plan
1. Add `page` (integer, default 1) and `pageSize` (integer, default 50, max 200) parameters to `task_list` schema in `packages/quay/src/mcp-server.js`.
2. After all filters applied (status, label, prefix, search), apply pagination.
3. Include pagination metadata in the returned JSON: `{ tasks, total, page, pageSize, totalPages }` in structuredContent.
4. Update tool description to document pagination.
5. Tests in mcp-server.test.mjs Block 15: default metadata, page slicing, disjoint sets, beyond-last-page, search+pagination ordering, schema check.
