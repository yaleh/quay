## Proposal
Close CB-015: MCP task_list only supports single `label` parameter. CLI and Web UI both support AND-join multi-label filtering. MCP users cannot replicate this.

## Plan
- Change `label` parameter in mcp-server.js inputSchema from `z.string().optional()` to `z.union([z.array(z.string()), z.string()]).optional()`
- Update handler to: `const labelFilters = Array.isArray(label) ? label : (label ? [label] : []);`
- Filter using AND-join: `if (labelFilters.length > 0) tasks = tasks.filter(t => labelFilters.every(l => Array.isArray(t.labels) && t.labels.includes(l)));`
- Update tool description to say "array of label strings for AND-join filtering (all specified labels must be present)"
- Add tests in mcp-server.test.mjs Block 16

## AC
- [x] `task_list` with `label: ["A", "B"]` returns only tasks with BOTH labels
- [x] `task_list` with `label: ["A"]` (single-element array) works same as before
- [x] `task_list` with `label: "A"` (string, backward compat) still works
- [x] `task_list` with `label: []` (empty array) — no filter applied (all tasks returned)
