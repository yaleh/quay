## Proposal
Close CB-008 and apply DIR-004: produce release artifacts for quay so users do not need to clone the repo. Approach: Option B (npm pack) chosen over Node SEA because esbuild is not available and SEA requires bundling all dependencies (yaml, @modelcontextprotocol/sdk) into a single file — doable but complex without a bundler. npm pack produces a self-contained .tgz installable via `npm install -g`.

## Plan
- Create `packages/quay/scripts/package.sh`: runs `npm pack` in packages/quay/, outputs versioned .tgz
- Create `.github/workflows/release.yml`: trigger on `push: tags: ['v*']`; build npm pack; upload to GitHub Release as artifact
- Validate: `bash packages/quay/scripts/package.sh` exits 0 and produces a .tgz
- Update gap-list.md to close CB-008
