## Proposal

`packages/quay/src/serve.js` calls `server.listen(port)` with no host arg — Node binds all interfaces (0.0.0.0) by default — but the log line hard-codes `http://localhost:${port}`, misleading the G7 precondition check into reading it as localhost-only.

Fix: either bind explicitly with `server.listen(port, "0.0.0.0", ...)` OR correct the log line to say `http://0.0.0.0:${port}` (or similar honest representation). Verify external reachability with evidence.

2. Change to explicit bind `server.listen(port, "0.0.0.0", callback)` and update log line
