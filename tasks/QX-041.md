## Proposal

`stripHeadings()` in `serve.js` filters any line matching `/^#+\s/`, including lines inside fenced code blocks (e.g., `# this is a bash comment` inside a ` ``` ` block). This means code-block content with `#`-prefixed comments is excluded from the full-text search index — a false negative for body search.

Fix: track whether the line iterator is inside a fenced code block (same toggle logic as `renderMarkdown` uses) and skip the heading filter for lines inside fences.

Closes SH-003 (minor, G3 PASS-WITH-NOTES, iteration 7).
