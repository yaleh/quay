## Proposal

`quay task list --json` (and `--prefix X --json`) emits a `# filtered: …` comment line before the JSON array when `--prefix` is active. This breaks automated JSON parsing (`jq`, `JSON.parse`) because the comment is not valid JSON. CB-020 filed by simulated-user (search power user, iteration 11).

## Plan

1. In `packages/quay/bin/quay.js`, move the `# filtered:` comment log to the non-JSON branch only (it's already inside the `if (flags.json)` block incorrectly, or the logic needs guarding).
2. Add a test in `packages/quay/test/cli.test.mjs` asserting `--prefix X --json` output parses as valid JSON with `JSON.parse()` directly (no slice/workaround).
