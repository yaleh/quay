## Proposal

When `?q=` is active and results span multiple pages, the search result banner shows "Showing N results for 'query'" but does not indicate which page the user is on or how many pages exist. Users may not notice the pagination links below the table. UQ-035 filed by simulated-user (search power user, iteration 11).

## Plan

1. In `packages/quay/src/serve.js`, update `searchResultBanner` to include "· Page X of Y" when `totalPages > 1`.
2. Add test assertions in `packages/quay/test/serve.test.mjs` (QX-046 block) confirming the page indicator appears when search spans multiple pages, and does not appear when results fit on one page.
