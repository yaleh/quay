## Summary

`--format json` is silently ignored by the CLI. parseFlags() sets flags.format="json" but the code only checks flags.json (boolean from --json). Scripts using --format json receive human-readable output instead of JSON, with no error signal.

## Fix

In parseFlags post-processing (or at the use-site), alias `flags.format === "json"` → `flags.json = true` so both `--json` and `--format json` activate the JSON output path.

## Acceptance Criteria

- [ ] `quay task list --format json` produces valid JSON output (same as --json)
- [ ] `quay task list --format unknown` produces an error message or falls back to human-readable (not silently wrong)
- [ ] Regression test added in cli.test.mjs confirming --format json == --json output
- [ ] All existing tests still pass
