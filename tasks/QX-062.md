# QX-062: CB-022 — fix --page-size ignored in JSON output mode

## Problem

`printJson(sorted)` at ~line 268 of `bin/quay.js` ignored `displayTasks` (the paginated
slice). Scripts combining `--page-size N` with `--json` or `--format json` received ALL
tasks regardless of the page-size flag. Significant gap for CLI scripting use cases.

## Fix (iteration 17, worktree commit 39038c8)

- `printJson(sorted)` → `printJson(displayTasks)` (one-line fix, closes CB-022)
- `--format json` alias carry-forward from QX-048/QX-058 (missing from worktree cherry-pick base)
- UQ-048 invalid-value warning bundled in same validation block
